One JSON sidecar per page is published beside the site, at cards///payload.json so a spec locates a page's record from the page's own identity rather than from a URL the module chose. Three call shapes, selected by front matter, because the entry treats them differently and a fixture that only ever used one would leave the other two unproven: - no front-matter marker: the bare Page, the standalone call, so the module derives the title and the description itself; - handed_title (with handed_description): the dict form the generated-image hook uses, so the strings the caller supplies are what gets drawn -- handed_title deliberately disagrees with .Title on one page, which is the only shape that can tell a module honoring the contract from one re-deriving the page title; - card_variant: a SECOND call for the same page naming a different variant and template, which is how one page carries more than one card. The recorder also dumps the scalar half of og-image/config.html's resolved options.
