{{/* og-image/config.html -- INTERNAL (resolver tier). Purpose: resolves the module's entire configuration through the four-tier cascade, so every downstream partial renders from ONE normalized options dict and nothing re-derives a value. Precedence, highest first: call-site opts > page front matter (ogcard: map) > site params ([params.ogcard]) > data/og-image/defaults.toml. Presence wins at every tier (isset, not truthiness), so an explicit false, 0, or "" overrides the tier below it. The table keys (templates, fonts, sections, kinds) merge per NAME across tiers, so a page can override one template's background without restating its slots. The `text` and `overlay` ARRAYS inside a template are REPLACED wholesale by a higher tier: Hugo's merge does not merge slices, and index-wise slot merging would be an invented semantic nobody could predict. For the same reason a page writing its own `ogcard:` map replaces a cascaded one wholesale -- that is Hugo's semantic for front matter, not the module's. Config and front-matter keys are lower-cased by Hugo, so template, font, section and kind names are effectively lower case, and names are looked up lower-cased throughout. Glyph width tables therefore cannot live in params at all (the folding would collapse "W" into "w"); they live in data files. EVERY tier is a consumer surface, the data tier included: a site may ship its own data/og-image/defaults.* and Hugo merges it into the same key. A tier whose shape is wrong is therefore reported and replaced with an empty table rather than indexed, because `index` on a scalar or a list raises and would stop the consuming site's build. Every tier is read through $page.Site.Params, never the global `site`: the global names the RENDERING language, and a card composed for a translation must read that translation's configuration. Context (dict): - .page (Page) The current page (already validated by the caller). - .opts (map) Call-site options (possibly empty). Carries `variant`, which exists at this tier only. Return value: dict with enable, width, height, format, quality, anchor, template, default_template, variant, templates, fonts, sections, kinds, typography (the nine module-level type keys, resolved by og-image/resolve/typography.html and overridable per card template and per text slot), and where (the diagnostics origin: the page path). One terminal return. */}} {{- $page := .page -}} {{- $lang := $page.Language.Lang -}} {{- $where := printf "%v" $page.Path -}} {{/* Tier 1: the data files, which a site can override with its own data/og-image/defaults.* of any shape at all. */}} {{- $data := index hugo.Data "og-image" -}} {{- if not (reflect.IsMap $data) -}}{{- $data = dict -}}{{- end -}} {{- $defaults := index $data "defaults" -}} {{- if and (ne $defaults nil) (not (reflect.IsMap $defaults)) -}} {{- partial "og-image/lib/warn.html" (dict "key" "og-image:warn:nonmap-config:defaults" "message" (printf "[og-image] Ignoring data/og-image/defaults.*: expected a table of keys, got %q. The shipped defaults do not apply, so only explicitly configured values do." (printf "%v" $defaults))) -}} {{- else if not $defaults -}} {{- partial "og-image/lib/warn.html" (dict "key" "og-image:warn:missing-defaults" "message" "[og-image] data/og-image/defaults.toml was not found; the module is not mounted correctly, so only explicitly configured values apply.") -}} {{- end -}} {{- if not (reflect.IsMap $defaults) -}}{{- $defaults = dict -}}{{- end -}} {{/* Tier 2: site params, read per language. */}} {{- $sitep := $page.Site.Params.ogcard -}} {{- $siteSet := ne $sitep nil -}} {{- if not (reflect.IsMap $sitep) -}} {{- if $siteSet -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:nonmap-config:site:%s" $lang) "message" (printf "[og-image] Ignoring params.ogcard for language %q: expected a table, got %q. To turn the module off site-wide, set params.ogcard.enable = false." $lang (printf "%v" $sitep))) -}} {{- end -}} {{- $sitep = dict -}} {{- end -}} {{/* Tier 3: page front matter, which a Hugo cascade can set for a section. */}} {{- $pagep := $page.Params.ogcard -}} {{- $pageSet := ne $pagep nil -}} {{- if not (reflect.IsMap $pagep) -}} {{- if $pageSet -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:nonmap-config:%s" $where) "message" (printf "[og-image] Ignoring the ogcard front matter value on %s: expected a table, got %q. To turn the card off for this page, set ogcard: { enable: false }." $where (printf "%v" $pagep))) -}} {{- end -}} {{- $pagep = dict -}} {{- end -}} {{/* Tier 4: the call site. Never populated by the seo hook; it exists so a direct caller can request a second card for one page, which front matter -- one value per page -- cannot express. */}} {{- $callp := .opts -}} {{- if not (reflect.IsMap $callp) -}} {{- if ne $callp nil -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:nonmap-config:call:%s" $where) "message" (printf "[og-image] Ignoring the opts argument passed to og-image/card.html on %s: expected a table, got %q." $where (printf "%v" $callp))) -}} {{- end -}} {{- $callp = dict -}} {{- end -}} {{- $tiers := slice $defaults $sitep $pagep $callp -}} {{/* Names the tier a value came from, positionally parallel to $tiers. A diagnostic must blame the CONFIGURATION that carries the mistake, not the page that happened to resolve it first: a site-wide params.ogcard typo is read by every page, so naming a page there points the maintainer at a file containing nothing wrong. The two per-page tiers keep the page path, because there the page IS the origin -- which also keeps their dedup keys per-page, so the same mistake repeated on two pages surfaces twice. */}} {{- $tierNames := slice "data/og-image/defaults.toml" (printf "params.ogcard for language %q" $lang) (printf "the ogcard front matter on %s" $where) (printf "the opts argument passed on %s" $where) -}} {{- $opts := dict "where" $where -}} {{/* ---- Bool keys ---- */}} {{- $truthy := slice "true" "1" "yes" "on" -}} {{- range $k := slice "enable" -}} {{- $v := index $defaults $k -}} {{- range $tier := $tiers -}} {{- if isset $tier $k -}}{{- $v = index $tier $k -}}{{- end -}} {{- end -}} {{- $opts = merge $opts (dict $k (in $truthy (lower (printf "%v" $v)))) -}} {{- end -}} {{/* ---- Int keys. A value that does not parse, or falls outside its range, warns once and leaves the shipped mechanical default in place. ---- */}} {{- range $sp := slice (dict "k" "width" "d" 1200 "lo" 1 "hi" 100000) (dict "k" "height" "d" 630 "lo" 1 "hi" 100000) (dict "k" "quality" "d" 75 "lo" 1 "hi" 100) -}} {{- $v := $sp.d -}} {{- $raw := "" -}} {{- $found := false -}} {{- $origin := "" -}} {{- range $i, $tier := $tiers -}} {{- if isset $tier $sp.k -}} {{- $raw = index $tier $sp.k -}} {{- $found = true -}} {{- $origin = index $tierNames $i -}} {{- end -}} {{- end -}} {{- if $found -}} {{- $n := partial "og-image/lib/int.html" $raw -}} {{- if and $n.ok (ge $n.value $sp.lo) (le $n.value $sp.hi) -}} {{- $v = $n.value -}} {{- else -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:bad-int:%s:%v:%s" $sp.k $raw $origin) "message" (printf "[og-image] Ignoring ogcard.%s value %q set in %s (expected a whole number from %d to %d); using %d instead." $sp.k (printf "%v" $raw) $origin $sp.lo $sp.hi $sp.d)) -}} {{- end -}} {{- end -}} {{- $opts = merge $opts (dict $sp.k $v) -}} {{- end -}} {{/* ---- Enum keys. `canonical` says whether the ACCEPTED value is stored lower-cased. format is: the composer decides whether to append the quality token by testing the stored value against a lower-case list, so a site writing "JPEG" would otherwise pass a case-insensitive check here and then silently lose its quality setting downstream. anchor is not: it is only ever handed to Hugo's Fill spec, which reads it case-insensitively, and its shipped spelling is what the data file and the documentation name. ---- */}} {{- range $sp := slice (dict "k" "format" "allowed" (slice "png" "jpeg" "webp") "fallback" "png" "canonical" true) (dict "k" "anchor" "allowed" (slice "topleft" "top" "topright" "left" "center" "right" "bottomleft" "bottom" "bottomright" "smart") "fallback" "Center" "canonical" false) -}} {{- $v := printf "%v" (index $defaults $sp.k | default $sp.fallback) -}} {{- $origin := index $tierNames 0 -}} {{- range $i, $tier := $tiers -}} {{- if isset $tier $sp.k -}} {{- $v = printf "%v" (index $tier $sp.k) -}} {{- $origin = index $tierNames $i -}} {{- end -}} {{- end -}} {{- $v = trim $v " \t\n\r" -}} {{- if not (in $sp.allowed (lower $v)) -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:unknown-enum:%s:%s:%s" $sp.k $v $origin) "message" (printf "[og-image] Unknown ogcard.%s value %q set in %s; using %q instead (allowed: %s)." $sp.k $v $origin $sp.fallback (delimit $sp.allowed ", "))) -}} {{- $v = $sp.fallback -}} {{- else if $sp.canonical -}} {{- $v = lower $v -}} {{- end -}} {{- $opts = merge $opts (dict $sp.k $v) -}} {{- end -}} {{/* ---- String keys. A table, list or boolean names no template, and a key written with no value at all names none either: stringifying any of them would hand the router the literal name "map[]", "false" or "", which no [templates] table can define and which stops the routing walk at a name that cannot exist. Each is ignored instead, so the tier below it stands and the router still tries the section, kind and default_template candidates. Only the shapes an author plausibly meant as a name speak; an empty key is the same statement as an empty string and stays silent. ---- */}} {{- range $k := slice "template" "default_template" -}} {{- $v := printf "%v" (index $defaults $k | default "") -}} {{- range $tier := $tiers -}} {{- if isset $tier $k -}} {{- $tv := index $tier $k -}} {{- if or (reflect.IsMap $tv) (reflect.IsSlice $tv) (eq (printf "%T" $tv) "bool") -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:template-shape:ogcard.%s:%v" $k $tv) "message" (printf "[og-image] Ignoring ogcard.%s: it expects a template name written as a single value but was given %q. That tier's value is dropped, so a lower-priority tier's value stands and the card may be drawn from a different template." $k (printf "%v" $tv))) -}} {{- else if ne $tv nil -}} {{- $v = printf "%v" $tv -}} {{- end -}} {{- end -}} {{- end -}} {{- $opts = merge $opts (dict $k (trim $v " \t\n\r")) -}} {{- end -}} {{/* ---- variant: the call tier ONLY. It is the memo discriminator that lets one page carry more than one card, and it is part of a card's identity together with the page and the language. ---- */}} {{- $variant := "" -}} {{- if isset $callp "variant" -}} {{- $variant = trim (printf "%v" (index $callp "variant")) " \t\n\r" -}} {{- end -}} {{- $opts = merge $opts (dict "variant" $variant) -}} {{/* ---- Typography: the nine keys that describe HOW text is rendered rather than where one slot sits, resolved ONCE here for the whole site. A card template overrides what it sets, and a text slot overrides that again -- the same normalization and the same diagnostics at all three levels, which is why resolve/typography.html owns the parsing for every one of them. Setting a face and a line height here is how a site says it once for every card it publishes. The values below are the module's fallbacks for a key no tier carries, and they duplicate the shipped data file the way the int and enum fallbacks above do: a site that replaces data/og-image/defaults.* still gets a card. `font` is deliberately absent from that data file and empty here, because the module ships no fonts and an unset face means Hugo's built-in one, which is Hugo's decision rather than this module's. ---- */}} {{- $opts = merge $opts (dict "typography" (partial "og-image/resolve/typography.html" (dict "tiers" $tiers "origins" $tierNames "defaults" (dict "font" "" "metrics" "default" "ellipsis" "…" "overflow" "shrink" "shrink_step" 4 "line_height" 1.4 "safety" 0.98 "min_scale" 0.7 "width_factor" 1.0)))) -}} {{/* ---- Tables: merged per NAME across tiers ---- */}} {{- range $name := slice "templates" "fonts" "sections" "kinds" -}} {{- $m := dict -}} {{- range $tier := $tiers -}} {{- $tv := index $tier $name -}} {{- if reflect.IsMap $tv -}} {{- $m = merge $m $tv -}} {{- else if ne $tv nil -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:nonmap-section:%s:%v" $name $tv) "message" (printf "[og-image] Ignoring the ogcard.%s configuration value: expected a table of named entries, got %q. See %s" $name (printf "%v" $tv) $where)) -}} {{- end -}} {{- end -}} {{- $opts = merge $opts (dict $name $m) -}} {{- end -}} {{/* A site that imported the module and can never draw anything has no other signal: every per-page decline below is silent by contract. The module ships no card template, so the question is whether ANY template table exists -- not whether this one page carries configuration, which would accuse a site that configures its cards entirely in front matter of being unconfigured on every page that does not. The merged table answers for this page and one pass over the language's pages answers for the rest, memoized per language because the answer is a property of the build. Two pages reaching that memo at once is harmless, unlike the check-then-set a warning key needs: the scan is a pure function of the content, so a second one computes the same answer, and the message it leads to is deduplicated by lib/warn.html either way. The language is part of the key so a multilingual site hears about each language that is missing the table. */}} {{- if not (index $opts "templates") -}} {{- $seenKey := printf "og-image:templates-defined:%s" $lang -}} {{- $seen := hugo.Store.Get $seenKey -}} {{- if not $seen -}} {{- $seen = "none" -}} {{- range $p := $page.Site.Pages -}} {{- $pm := $p.Params.ogcard -}} {{- if reflect.IsMap $pm -}} {{- if index $pm "templates" -}}{{- $seen = "some" -}}{{- end -}} {{- end -}} {{- end -}} {{- hugo.Store.Set $seenKey $seen -}} {{- end -}} {{- if eq $seen "none" -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:unconfigured:%s" $lang) "message" (printf "[og-image] No params.ogcard configuration was found for language %q that defines a card template, and no page's front matter defines one either, so no page can be carded. Define at least one card template ([params.ogcard.templates.] with a background) and route pages to it." $lang)) -}} {{- end -}} {{- end -}} {{- return $opts -}}
