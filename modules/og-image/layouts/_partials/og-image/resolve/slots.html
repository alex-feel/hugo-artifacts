{{/* og-image/resolve/slots.html -- INTERNAL (resolver tier). Purpose: turns a card template's `text` array into the images.Text filters that draw it, one filter PER LINE. Why per line: for a single-line filter Hugo places the text at the same vertical position whatever the horizontal alignment, while a multi-line filter couples alignment and line pitch and merges lines at card sizes under its own default spacing. Drawing one line per filter takes that coupling out of the picture: `x` is an absolute canvas coordinate naming where the alignment anchor sits, `y` is computed per line as the slot's y plus the line index times the pitch, and `linespacing` is never set because no filter here carries more than one line. All the filters still go into a single images.Filter call, so N lines still cost ONE derivative. A slot with `width` set runs through the fit engine: the text is measured once in per-mille em and wrapped against the box, shrinking down a bounded size ladder until it fits or reaching the ladder's floor and truncating with an ellipsis. A slot WITHOUT `width` never wraps, but it still draws one filter per newline already in its value -- a multi-line literal, or a flat list joined one item per line -- at the same resolved line pitch, because handing images.Text the newlines instead is exactly the coupling this per-line scheme exists to avoid. A multi-line slot therefore defaults like a wrapping one -- size taken as 20, `x` and `y` as 0, align as left -- with `y` the top of the first line. The width estimate never enters positioning -- it decides line breaks only. Every key of the option dict is written out by name, because images.Text silently ignores an option key it does not know: a typo would be invisible except in the pixels. A key the site did not set is OMITTED rather than defaulted here, so Hugo's own documented default applies and the module invents no value. The nine TYPOGRAPHY keys -- font, metrics, line_height, safety, width_factor, min_scale, shrink_step, overflow and ellipsis -- are not slot keys alone: each resolves as slot value, else card-template value, else the module-level value config.html already cascaded through its own four tiers. All three levels are read, normalized and reported by og-image/resolve/typography.html, so a value written anywhere means the same thing and a bad one anywhere falls back to the level below it. What stays per-slot here is what describes THIS element rather than the site's type: its source, geometry, alignment and color. Context (dict): - .page (Page) The current page. - .opts (dict) The resolved options from og-image/config.html. - .name (string) The card template's name. - .template (map) The card template's table. - .title (string) The resolved title handed to card.html. - .description (string) The resolved description handed to card.html. Return value: dict{filters (slice), filters_nofont (slice), drew (bool), fonts (slice of string)} -- filters_nofont repeats every filter with the font key removed, so the composer can retry in Hugo's built-in face when a font resource turns out to be unparseable. One terminal return. */}} {{- $page := .page -}} {{- $opts := .opts -}} {{- $name := .name -}} {{- $tpl := .template -}} {{- $filters := slice -}} {{- $nofont := slice -}} {{- $fonts := slice -}} {{- $drew := false -}} {{- $slots := partial "og-image/lib/as-map-list.html" (dict "value" (index $tpl "text") "key" (printf "og-image:warn:bad-text-entry:%s" $name) "label" (printf "the text of card template %q" $name)) -}} {{/* The card template's own typography, read once for the whole template: it overrides the module level for every slot of this card that does not set its own. */}} {{- $tplType := partial "og-image/resolve/typography.html" (dict "tiers" (slice $tpl) "origins" (slice (printf "card template %q" $name))) -}} {{- range $i, $slot := $slots -}} {{- $src := partial "og-image/resolve/source.html" (dict "page" $page "slot" $slot "title" $.title "description" $.description "name" $name) -}} {{- if $src.ok -}} {{/* ---- Integer geometry. A value that does not parse warns once and that ONE key falls back to its documented default; the rest of the slot still draws. ---- */}} {{- $ints := dict -}} {{- $has := dict -}} {{- range $sp := slice (dict "k" "size" "d" 20 "lo" 1 "hi" 100000) (dict "k" "x" "d" 0 "lo" -100000 "hi" 100000) (dict "k" "y" "d" 0 "lo" -100000 "hi" 100000) (dict "k" "width" "d" 0 "lo" 1 "hi" 100000) (dict "k" "max_lines" "d" 0 "lo" 0 "hi" 100000) -}} {{- $v := $sp.d -}} {{- $present := false -}} {{- if isset $slot $sp.k -}} {{- $n := partial "og-image/lib/int.html" (index $slot $sp.k) -}} {{- if and $n.ok (ge $n.value $sp.lo) (le $n.value $sp.hi) -}} {{- $v = $n.value -}} {{- $present = true -}} {{- else -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:bad-int:%s:%d:%s:%v" $name $i $sp.k (index $slot $sp.k)) "message" (printf "[og-image] Ignoring the %s value %q on text slot %d of card template %q (expected a whole number from %d to %d); that key falls back to its default." $sp.k (printf "%v" (index $slot $sp.k)) $i $name $sp.lo $sp.hi)) -}} {{- end -}} {{- end -}} {{- $ints = merge $ints (dict $sp.k $v) -}} {{- $has = merge $has (dict $sp.k $present) -}} {{- end -}} {{/* ---- Typography, most specific level first: this slot, else the card template it belongs to, else the module level config.html resolved. The module-level dict carries every one of the nine keys, so it names the key set the two levels above it may override -- each of those returns only what it actually set, and a value that failed its check there is simply not among them. ---- */}} {{- $slotType := partial "og-image/resolve/typography.html" (dict "tiers" (slice $slot) "origins" (slice (printf "text slot %d of card template %q" $i $name))) -}} {{- $type := dict -}} {{- range $k, $mv := $opts.typography -}} {{- $v := $mv -}} {{- if isset $tplType $k -}}{{- $v = index $tplType $k -}}{{- end -}} {{- if isset $slotType $k -}}{{- $v = index $slotType $k -}}{{- end -}} {{- $type = merge $type (dict $k $v) -}} {{- end -}} {{/* ---- Enums ---- */}} {{- $align := "left" -}} {{- $hasAlign := false -}} {{- if isset $slot "align" -}} {{- $a := lower (trim (printf "%v" (index $slot "align")) " \t\n\r") -}} {{- if in (slice "left" "center" "right") $a -}} {{- $align = $a -}} {{- $hasAlign = true -}} {{- else -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:unknown-enum:align:%s" $a) "message" (printf "[og-image] Unknown align value %q on text slot %d of card template %q; using \"left\" instead (allowed: left, center, right)." $a $i $name)) -}} {{- end -}} {{- end -}} {{/* ---- Color. Hugo accepts a value it cannot read and silently draws white, with no diagnostic of its own, so this warning is the only thing standing between a typo and a card of invisible text. An invalid value drops the key, which is what makes Hugo's own documented default apply. ---- */}} {{- $color := "" -}} {{- if isset $slot "color" -}} {{- $c := trim (printf "%v" (index $slot "color")) " \t\n\r" -}} {{- if findRE `^#([0-9a-fA-F]{3}|[0-9a-fA-F]{6})$` $c -}} {{- $color = $c -}} {{- else -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:bad-color:%s:%s" $name $c) "message" (printf "[og-image] Ignoring the color value %q on text slot %d of card template %q: a color is written as \"#rgb\" or \"#rrggbb\". Hugo draws an unreadable color as white without saying so, so check this card." $c $i $name)) -}} {{- end -}} {{- end -}} {{/* ---- Font: the NAME this slot resolved to -- its own, its card template's, or the site's -- names a registry entry, which resolves to a resource or to nothing. A name the registry does not define is a typo worth one warning; the slot still draws in Hugo's built-in face. ---- */}} {{- $font := "" -}} {{- $fontLabel := "" -}} {{- $fname := $type.font -}} {{- if $fname -}} {{- $fpath := "" -}} {{- $fraw := index $opts.fonts $fname -}} {{- if and (ne $fraw nil) (not (reflect.IsMap $fraw)) (not (reflect.IsSlice $fraw)) -}} {{- $fpath = trim (printf "%v" $fraw) " \t\n\r" -}} {{- end -}} {{- if $fpath -}} {{- $font = partialCached "og-image/resolve/font.html" (dict "name" $fname "path" $fpath) $fpath -}} {{- $fontLabel = printf "%s (%s)" $fname $fpath -}} {{- else -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:unknown-font:%s" $fname) "message" (printf "[og-image] No font named %q is registered under [params.ogcard.fonts], so the slots asking for it are drawn with Hugo's built-in Go Regular instead." $fname)) -}} {{- end -}} {{- end -}} {{- if and $font (not (in $fonts $fontLabel)) -}} {{- $fonts = $fonts | append $fontLabel -}} {{- end -}} {{/* ---- Emit the filters ---- */}} {{- $emit := slice -}} {{- if $has.width -}} {{/* Wrapped slot: the fit engine decides the size and the line breaks, and each line is drawn as its own filter at its own y. */}} {{- $box := dict "size" $ints.size "width" $ints.width "max_lines" (cond (le $ints.max_lines 0) 1000000 $ints.max_lines) "shrink_step" $type.shrink_step "min_scale" $type.min_scale "safety" $type.safety "width_factor" $type.width_factor "overflow" $type.overflow "ellipsis" $type.ellipsis -}} {{/* An explicitly empty table name names no table, so it reads as the shipped one rather than as a lookup that must then be reported -- unlike an empty font name, which is a level saying "Hugo's built-in face" and is honored as written. */}} {{- $metricsName := $type.metrics -}} {{- if not $metricsName -}}{{- $metricsName = "default" -}}{{- end -}} {{- $metrics := partialCached "og-image/text/metrics.html" (dict "name" $metricsName) $metricsName -}} {{- $fit := partial "og-image/text/fit.html" (dict "text" $src.text "box" $box "metrics" $metrics) -}} {{/* The engine reports a line it had to place wider than its budget, which no size in the ladder could fix: the box is narrower than one glyph. Nothing else would say so -- the card publishes, and the ink simply runs past the box the slot declared. */}} {{- if $fit.over_budget -}} {{- partial "og-image/lib/warn.html" (dict "key" (printf "og-image:warn:narrow-box:%s:%d" $name $i) "message" (printf "[og-image] The %d-pixel box of text slot %d of card template %q is narrower than a single glyph at the sizes the slot allows, so its lines are drawn running past the box. Widen width, lower size, or lower min_scale." $ints.width $i $name)) -}} {{- end -}} {{- $pitch := int (math.Round (mul (float $fit.size) (float $type.line_height))) -}} {{- if lt $pitch 1 -}}{{- $pitch = 1 -}}{{- end -}} {{- $anchor := $ints.x -}} {{- if eq $align "center" -}} {{- $anchor = add $ints.x (int (math.Floor (div (float $ints.width) 2.0))) -}} {{- else if eq $align "right" -}} {{- $anchor = add $ints.x $ints.width -}} {{- end -}} {{- range $li, $line := $fit.lines -}} {{- $emit = $emit | append (dict "text" $line "opts" (dict "size" $fit.size "x" $anchor "y" (add $ints.y (mul $li $pitch)) "alignx" $align "aligny" "top")) -}} {{- end -}} {{- else -}} {{/* Unwrapped slot: no fit engine, and only the keys the site actually set. Hugo word-wraps at the canvas edge on its own when a line does not fit, which is a silent backstop, not a placement this module chose: set `width` to lay the text out here instead. A value that already carries newlines is still drawn one filter per line at the resolved pitch -- handed to images.Text whole, its lines merge at card sizes under Hugo's own spacing. */}} {{- $lines := split (replaceRE `\r\n?` "\n" $src.text) "\n" -}} {{- if le (len $lines) 1 -}} {{- $o := dict "aligny" "top" -}} {{- if $has.size -}}{{- $o = merge $o (dict "size" $ints.size) -}}{{- end -}} {{- if $has.x -}}{{- $o = merge $o (dict "x" $ints.x) -}}{{- end -}} {{- if $has.y -}}{{- $o = merge $o (dict "y" $ints.y) -}}{{- end -}} {{- if $hasAlign -}}{{- $o = merge $o (dict "alignx" $align) -}}{{- end -}} {{- $emit = $emit | append (dict "text" $src.text "opts" $o) -}} {{- else -}} {{/* A multi-line slot defaults exactly like a wrapping one -- size taken as 20, x and y as 0, align as left -- so drawing more than one line is ONE contract wherever the lines came from. An all-whitespace line emits no filter and still advances the count, so a deliberate blank line stays a visible gap. */}} {{- $pitch := int (math.Round (mul (float $ints.size) (float $type.line_height))) -}} {{- if lt $pitch 1 -}}{{- $pitch = 1 -}}{{- end -}} {{- range $li, $line := $lines -}} {{- if ne (trim $line " \t") "" -}} {{- $emit = $emit | append (dict "text" $line "opts" (dict "size" $ints.size "x" $ints.x "y" (add $ints.y (mul $li $pitch)) "alignx" $align "aligny" "top")) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- range $e := $emit -}} {{- $o := $e.opts -}} {{- if $color -}}{{- $o = merge $o (dict "color" $color) -}}{{- end -}} {{- $nofont = $nofont | append (images.Text $e.text $o) -}} {{- $withFont := $o -}} {{- if $font -}}{{- $withFont = merge $o (dict "font" $font) -}}{{- end -}} {{- $filters = $filters | append (images.Text $e.text $withFont) -}} {{- $drew = true -}} {{- end -}} {{- end -}} {{- end -}} {{- return (dict "filters" $filters "filters_nofont" $nofont "drew" $drew "fonts" $fonts) -}}
