{{/* og-image/text/wrap.html -- INTERNAL (text tier). Purpose: greedy word wrap against a per-mille-em budget. The function is TOTAL: it returns at most max_lines lines for EVERY input, with overflow=true when content had to be dropped. That is what lets the fitter treat the shrink ladder as "the first rung whose overflow is false" and still hold a usable answer when no rung fits. Fitting has TWO failure modes and they are reported separately. overflow says content was DROPPED; over_budget says a line that WAS placed is wider than the budget, which happens only when the budget is narrower than one glyph: a fresh line accepts its first piece whatever its width, because refusing it would drop a character or fail to terminate. Reporting only the first would let the fitter accept a rung whose ink runs past the box and call it a fit. A word wider than the budget is hard-split. A hard break flushes the current line even when it is empty, so an author's blank line survives. Truncation keeps the LONGEST PREFIX of the last allowed line that leaves room for the ellipsis -- accumulated width is monotonic, so one forward pass finds it -- and when not even the first piece fits, that piece is itself split against budget minus the ellipsis width, so a single over-long word truncates to a readable head plus the ellipsis rather than to a bare ellipsis. The ellipsis is appended only when the truncated line still fits the budget with it: truncation must never hand back a line WIDER than the content it replaced, which is what appending it unconditionally does once the ellipsis alone is wider than the room left for it. Hugo has no `while` and no `break`: every loop here ranges over a finite slice guarded by an early-exit flag, so termination is structural. Context (dict): - .tokens (slice) Tokens from og-image/text/measure.html. - .space (int) Separator width in per-mille em. - .budget (int) Line budget in per-mille em. - .max_lines (int) Hard line bound (callers pass a large sentinel for "unlimited"). - .ellipsis (string) Appended to a truncated last line. - .ellipsis_w (int) Width of that ellipsis. - .glyphs (map) Per-glyph widths, for hard-splitting. - .fallback (int) Width for a glyph the table does not name. Return value: dict{lines (slice of string), widths (slice of int), overflow (bool), over_budget (bool)}. One terminal return. */}} {{- $tokens := .tokens -}} {{- $space := .space -}} {{- $budget := .budget -}} {{- $maxLines := .max_lines -}} {{- $ellipsis := .ellipsis -}} {{- $ellw := .ellipsis_w -}} {{- := false -}} {{- $wide := false -}} {{- range $tok := $tokens -}} {{- if not $stop -}} {{- if $tok.br -}} {{- if ge (len $lines) (sub $maxLines 1) -}} {{- $stop = true -}} {{- $over = true -}} {{-
