{{/* og-image/text/fit.html -- INTERNAL (text tier). Purpose: finds the largest size in a bounded descending ladder at which the text wraps within max_lines, and falls back to the smallest rung's truncated wrap when no rung fits. Words are measured ONCE, in per-mille em, and every rung re-wraps that same width vector against a different budget: budget = floor(box_width * em * safety * width_factor / size) TERMINATION IS STRUCTURAL: the ladder is a FIXED slice built before the loop, `range` walks it once with an early-exit flag, and wrap.html is total at every rung, so the worst case is exactly len(sizes) iterations with the last rung's truncated result as the answer. The ladder is capped at 25 entries (the base size plus at most 24 rungs); when the configured step would need more rungs than that to reach the floor, the STEP is widened so the ladder still spans size down to floor instead of stopping short. The floor is the ladder's LAST rung, always. Stepping down from size lands on it only when the step divides the span exactly, so the floor is appended whenever the stepped rungs stop above it -- the stepped rungs are all kept, because a size that fits is preferable to the smaller one below it, and the step budget is one rung shorter to hold the cap. Without that final rung the smallest size the author allowed is never tried, and text that would have fitted whole is truncated at a larger size instead. A rung is accepted when the wrap neither dropped content NOR left a placed line wider than the budget; a box narrower than a single glyph can only produce the latter, and shrinking is exactly what widens the per-mille budget that such a line overruns. The clamps below duplicate config normalization ON PURPOSE: the resolver warns for the author, and this partial stays total on its own so that no configuration -- including a size of 0, which would otherwise divide by zero and break the build -- can escape as a template error. Context (dict): - .text (any) The resolved slot text. - .box (dict) Normalized slot geometry: size, width, max_lines, shrink_step, min_scale, safety, width_factor, overflow, ellipsis. - .metrics (dict) A table from og-image/text/metrics.html. Return value: dict{lines, widths, overflow, over_budget, size, budget}. One terminal return. */}} {{- $box := .box -}} {{- $m := .metrics -}} {{- $em := $m.em -}} {{- if lt $em 1 -}}{{- $em = 1000 -}}{{- end -}} {{- $size := $box.size -}} {{- if lt $size 1 -}}{{- $size =
