{{/* og-image/text/fit.html -- INTERNAL (text tier). Purpose: finds the largest size in a bounded descending ladder at which the text wraps within max_lines, and falls back to the smallest rung's truncated wrap when no rung fits. Words are measured ONCE, in per-mille em, and every rung re-wraps that same width vector against a different budget: budget = floor(box_width * em * safety * width_factor / size) TERMINATION IS STRUCTURAL: the ladder is a FIXED slice built before the loop, `range` walks it once with an early-exit flag, and wrap.html is total at every rung, so the worst case is exactly len(sizes) iterations with the last rung's truncated result as the answer. The ladder is capped at 25 entries (the base size plus at most 24 rungs); when the configured step would need more rungs than that to reach the floor, the STEP is widened so the ladder still spans size down to floor instead of stopping short. The clamps below duplicate config normalization ON PURPOSE: the resolver warns for the author, and this partial stays total on its own so that no configuration -- including a size of 0, which would otherwise divide by zero and break the build -- can escape as a template error.
