{{/* og-image/lib/resolve-image.html -- INTERNAL (library tier). Purpose: turns one image SPEC -- a table naming where an image comes from -- into a usable image resource. It owns the source vocabulary for the whole module, so a background and an overlay name their artwork the same way and cannot drift apart: asset `src` a path under assets/, the shared artwork every card uses param `key` a front-matter key holding a path, resolved against the page's own bundle first and assets/ second resource `match` a glob matched against the page's own bundle It reports WHAT happened and never warns itself, because the same outcome means different things to different callers: a page not carrying the image is an ordinary skip for an overlay and a decline (or a fallback) for a background. The caller owns that judgment and the wording that goes with it. The usability probe runs here too. A resource can be media-typed as an image and still carry nothing Hugo can decode -- a media type is inferred from the extension, so a text file named .png reads as an image resource and would take the build down at the first pixel operation. Reading .Width is what finds out. Context (dict): - .page (Page) The current page. - .spec (map) The table naming the image (source, src, key, match). - .default (string) The source token to assume when the spec names none. Return value: dict{resource, label (string), source (string), reason (string), known (slice)}. `reason` is empty on success, and otherwise one of: unknown-source the source token is not in the vocabulary no-locator the source is known but its own src/key/match is missing bad-match the glob cannot be matched against any page's resources not-found an assets/ path that names no file (a template mistake) absent this page simply does not carry the image unusable something was found that Hugo cannot process as an image ONE terminal return. */}} {{- $page := .page -}} {{- $spec := .spec -}} {{- $known := slice "asset" "param" "resource" -}} {{- $source := lower (trim (printf "%v" (index $spec "source" | default .default)) " \t\n\r") -}} {{- $res := "" -}} {{- $label := "" -}} {{- $reason := "" -}} {{- if not (in $known $source) -}} {{- $reason = "unknown-source" -}} {{- else if eq $source "asset" -}} {{- $src := trim (printf "%v" (index $spec "src" | default "")) " \t\n\r" -}} {{- $label = $src -}} {{- if not $src -}} {{- $reason = "no-locator" -}} {{- else -}} {{/* resources.Get returns nil for a path that names no file, but RAISES when the operating system rejects the path itself -- one carrying `*`, `?`, or the `:` of a pasted URL is such a path on Windows. Both mean the same thing to the site that wrote it, so the caught error and the plain nil report the one reason. */}} {{- $got := try (resources.Get $src) -}} {{- with $got.Value -}} {{- $res = . -}} {{- else -}} {{- $reason = "not-found" -}} {{- end -}} {{- end -}} {{- else if eq $source "param" -}} {{/* A page that simply does not carry the parameter, or carries a value that names nothing, is the design rather than a mistake. The value is the PAGE's, and both lookups are wrapped for it: GetMatch RAISES on a value that is not a matchable pattern, and resources.Get RAISES on one the operating system rejects outright. Each caught error means here exactly what a nil means -- this page has no such image. */}} {{- $key := trim (printf "%v" (index $spec "key" | default "")) " \t\n\r" -}} {{- if not $key -}} {{- $reason = "no-locator" -}} {{- else -}} {{- $reason = "absent" -}} {{- $v := $page.Param $key -}} {{- if and (ne $v nil) (not (reflect.IsMap $v)) (not (reflect.IsSlice $v)) -}} {{- $p := trim (printf "%v" $v) " \t\n\r" -}} {{- $label = $p -}} {{- if $p -}} {{- $bundled := try ($page.Resources.GetMatch $p) -}} {{- with $bundled.Value -}} {{- $res = . -}} {{- $reason = "" -}} {{- else -}} {{- $got := try (resources.Get $p) -}} {{- with $got.Value -}} {{- $res = . -}} {{- $reason = "" -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- else -}} {{- $match := trim (printf "%v" (index $spec "match" | default "")) " \t\n\r" -}} {{- $label = $match -}} {{- if not $match -}} {{- $reason = "no-locator" -}} {{- else -}} {{/* The pattern is the card template's, so an unmatchable one is a configuration mistake no page can satisfy: GetMatch RAISES on it (an unclosed `[` is enough, and it raises even on a page with no resources, because the pattern is compiled before anything is matched). A pattern that is fine and simply matches nothing is the page not carrying the image. */}} {{- $bundled := try ($page.Resources.GetMatch $match) -}} {{- if $bundled.Err -}} {{- $reason = "bad-match" -}} {{- else -}} {{- with $bundled.Value -}} {{- $res = . -}} {{- else -}} {{- $reason = "absent" -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- if $res -}} {{- $usable := eq $res.ResourceType "image" -}} {{- if and $usable (eq $res.MediaType.SubType "svg") -}} {{- $usable = false -}} {{- end -}} {{- if $usable -}} {{- $probe := try $res.Width -}} {{- $usable = and (not $probe.Err) (gt (int ($probe.Value | default 0)) 0) -}} {{- end -}} {{- if not $usable -}} {{- $res = "" -}} {{- $reason = "unusable" -}} {{- end -}} {{- end -}} {{- return (dict "resource" $res "label" $label "source" $source "reason" $reason "known" $known) -}}
