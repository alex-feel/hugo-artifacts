The German section page exists as a file rather than by Hugo's own inference. Observed: Hugo v0.160.0 -- this module's declared floor -- publishes no section page for a secondary language's content directory that carries no `_index.md`, while v0.164.0 does, so a suite relying on the inferred page asserts a rule that exists at one version and not the other. The English side needs no such file: its section page is published at both.
