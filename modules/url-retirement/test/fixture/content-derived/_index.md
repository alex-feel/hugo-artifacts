The English home page of the `derived-urls` build, and the only home page in this suite that carries an alias. It exists to make the module answer one question out loud: what URL does a rule pointing at the home page name, on a site that lists html after this module's own formats? The shared content directory cannot carry this alias, because ten other builds assert their rule sets exactly and a home alias would appear in all of them.
