{{/* url-retirement/lib/manifest-path.html -- INTERNAL (lib tier). Purpose: validates ONE entry of url_retirement.manifest.extra or of url_retirement.manifest.exclude before it reaches the manifest. Both keys hold the same thing -- a server-relative path naming a URL -- so both are checked here, and the diagnostic names whichever key carried the entry. The container's shape is checked by config.html; this checks each ELEMENT, which is the half that matters downstream. The rule itself lives in lib/url-shape.html, shared with the registration path so a URL configured and a URL registered are held to one standard; this file is the half that says what a REJECTION cost the site, which the rule cannot know. An `extra` element is handed to lib/prefix-url.html, whose documented precondition is a server-relative path beginning with "/". An entry that is a nested table, or a bare word, or an absolute URL therefore does not merely look wrong: it is published as `map[...]`, as `/docsno-slash.html`, or as `/docshttps://elsewhere.example/`, in a document whose whole job is to be diffed byte for byte against production. An `exclude` element is compared against those same normalized paths, so a malformed one silently matches nothing, which is the quieter half of the same fault: the site believes a URL was removed and the manifest still carries it. So the rejection is at the edge, once, with a diagnostic, rather than in the places the value is later used. Expected context (dict): - .setting (string) "extra" or "exclude", naming the key in the diagnostic and choosing what the reader is told the rejection costs them. - .value (any) The raw element, of any type at all. Return value: the trimmed path when it is usable, "" when it is not. The caller skips the empty string. One terminal return. */}} {{- $setting := .setting -}} {{- $value := .value -}} {{- $consequence := cond (eq $setting "exclude") "Nothing is left out of /url-manifest.txt for it." "It is left out of /url-manifest.txt." -}} {{- $checked := partial "url-retirement/lib/url-shape.html" (dict "value" $value) -}} {{- $reasons := dict "shape" "an entry is one URL written as a single value" "relative" "entries are server-relative paths and must start with \"/\"" "network-path" "a value beginning with \"//\" is a protocol-relative URL naming another host, not a path on this site" "whitespace" "a URL in this document may not contain whitespace, because the file carries one URL per line" -}} {{- with $checked.fault -}} {{- if eq . "empty" -}} {{/* Reported rather than dropped in silence: an empty entry is a key the site filled in from something that resolved to nothing, and the value it meant to name is exactly what a reader would go looking for. */}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:%s-element-empty" $setting) "message" (printf "[url-retirement] Ignoring an empty url_retirement.manifest.%s entry. %s" $setting $consequence)) -}} {{- else -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:%s-element-%s:%v" $setting . $value) "message" (printf "[url-retirement] Ignoring the url_retirement.manifest.%s entry %q: %s. %s" $setting (printf "%v" $value) (index $reasons .) $consequence)) -}} {{- end -}} {{- end -}} {{- return $checked.path -}}
