{{/* url-retirement/lib/record-url.html -- INTERNAL (lib tier). Purpose: records ONE URL for one language's manifest, or says why it could not. Both public registration partials funnel through here -- register-url.html for a URL no page carries, register-pagers.html for a pager URL -- so the one way a registration can be lost is diagnosed once, in one place, rather than once per caller or not at all. THE LOSS THIS EXISTS FOR. Hugo renders one output format at a time within a language, positive weights ascending and then every zero-weight format, so /url-manifest.txt at weight 100 sees whatever the html pass (weight 10) recorded and nothing recorded afterwards. A registration that arrives late is not an error Hugo reports: the store accepts it, the build exits 0, and the URL is simply absent from a document whose whole purpose is to be complete. That is the same silent omission the manifest exists to prevent, arriving through the machinery meant to prevent it. So the manifest sets url-retirement:manifest-rendered: as it renders, and this partial reads it: a registration made after that point is refused with one warning naming the URL, rather than accepted into a map nothing will read again. The warning claims exactly what the sentinel entails -- that the registration could not reach the document -- and not that the URL is absent from it, because a URL can arrive by the page walk as well: a list page registers its own URL alongside its pagers, and that URL is in site.Pages too. A URL this language ALREADY recorded in time is not warned about at all, because a repeated registration of a URL that did reach the manifest is a caller doing nothing wrong. Measured at Hugo v0.164.0: a template rendering in a zero-weight format's pass reads the sentinel the weight-100 document set, while every html-pass template reads it as absent, so an in-time caller is never warned. The key carries the language because hugo.Store is build-global and each language renders completely before the next begins -- an unscoped sentinel reads as set during every language's html pass but the first, which would warn about every registration on a multilingual site that made none too late. WHICH LANGUAGE RENDERS FIRST is the language `weight` order rather than the default language first -- measured at v0.164.0. That only matters to a caller registering a URL for a language OTHER than the one being rendered, which the .page it passes decides: such a registration is refused whenever the target language has already rendered its own manifest, and whether it has is a property of the site's language weights. A caller passing the page it is rendering never meets this. A URL MINTED FOR ANOTHER HOST IS PUT BACK IN THIS ONE'S FRAME, by lib/host-frame.html, which carries the measurement and the residual ambiguity. The rule lives there rather than here because the writes hook the manifest asks meets the same thing, and one rule in two copies is one rule that drifts. The recorded map is keyed BY THE URL, which makes a repeated registration of the same URL idempotent, and SetInMap rather than Add because Add silently loses updates under the concurrent within-pass page rendering. Expected context (dict): - .page (Page) The page being rendered; names the language. - .url (string) A server-relative URL, already validated by the caller. Return value: none. Side effect: the URL is recorded for this build, or one warning is emitted for it. */}} {{- $page := .page -}} {{- $url := .url -}} {{- $lang := $page.Language.Name -}} {{- $url = partial "url-retirement/lib/host-frame.html" (dict "page" $page "url" $url) -}} {{- $key := printf "url-retirement:registered:%s" $lang -}} {{- $recorded := hugo.Store.Get $key -}} {{- if and (reflect.IsMap $recorded) (ne (index $recorded $url) nil) -}} {{/* Already recorded for this language, in time. Repeating a registration is what a partial called once per page does, and there is nothing to say about it. */}} {{- else if hugo.Store.Get (printf "url-retirement:manifest-rendered:%s" $lang) -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:registered-late:%s:%s" $lang $url) "message" (printf "[url-retirement] %s was registered for language %q after that language's /url-manifest.txt had already been written, so the registration could not reach it. A registration reaches the manifest only from a pass that renders BEFORE it: the urlmanifest format carries weight 100, so any format weighted below that is in time -- the html format at weight 10 included -- while a format carrying no weight renders after every weighted one and is not. Where the publishing template cannot choose which pass reaches it, the format's owner answers through a url-retirement/writes/.html hook instead, which this document asks in its own pass. Where the site owns the URL, name it in url_retirement.manifest.extra." $url $lang)) -}} {{- else -}} {{- hugo.Store.SetInMap $key $url $url -}} {{- end -}}
