{{/* url-retirement/register-url.html -- PUBLIC. Purpose: records a URL this build publishes that no walk of the page graph can reach, so /url-manifest.txt lists it. Call it from the template that PUBLISHES the URL, guarded so a site without this module pays nothing: {{ $sw := resources.Get "js/sw.js" | js.Build $opts }} {{ with $sw.RelPermalink }} {{ if templates.Exists "_partials/url-retirement/register-url.html" }} {{ partial "url-retirement/register-url.html" (dict "page" $page "url" .) }} {{ end }} {{ end }} The guard takes a path under layouts/ WITH the .html suffix, which `partial` itself does not need, and the pre-v0.146 `partials/` spelling silently returns false. Why the publisher has to make this call. The manifest is built by crossing every page in site.Pages with its output formats, and several things a build really publishes are in neither: a file the asset pipeline wrote, which is a Resource rather than a Page and exists only where a template read its URL; a page kept out of every page collection by build.list = never, which is how a module ships a page a site never lists; a file copied verbatim from static/, which Hugo exposes to no template at all. Nothing can enumerate those from outside, and the omission is the SILENT direction for this document -- a URL missing from the registry is one whose disappearance from production the coverage check can never report. The publisher is the only party that knows, so this is where it says so. REGISTER WHAT THE BUILD REALLY WROTE, not what it intends to write. Every other line in the manifest is evidence a file exists; a registration is the one arrival path that can ADD a line no file backs, which would put a URL production answers 404 for into a document meant to be diffed against production. Reading a Resource's .RelPermalink is what materializes it, so register the URL the read returned, at the point it returned it, and not from a branch that might not publish. DO NOT REGISTER A CONTENT-ADDRESSED URL -- a fingerprinted script, a processed image, anything carrying a hash of its own contents. Such a URL changes whenever its source does, by design, so listing it makes every rebuild report a retirement and a new URL in a file whose only use is showing what genuinely changed. The same goes for anything a development build publishes and a production build does not, such as a source map: a manifest that is structurally unequal to production's cannot be compared with it. ORDERING. Hugo renders one output format at a time within a language, positive weights ascending and then every zero-weight format, so /url-manifest.txt at weight 100 sees registrations made during the html pass (weight 10) and none made afterwards. Register from a template that renders in the html pass -- a layout, or a partial the consumer's reaches. A registration made from an output format's own template arrives after the manifest was written; it is refused with a warning naming the URL rather than silently dropped, but it is still not listed. Expected context (dict): - .page (Page) The page being rendered; names the language whose manifest the URL belongs to. - .url (string) One server-relative URL, beginning with "/". - .urls (slice) Several of them, when one call publishes more than one. Pass either key, or both. Return value: none. Side effect: the URLs are recorded for this build. */}} {{- $page := .page -}} {{- if not (reflect.IsPage $page) -}} {{- partial "url-retirement/lib/warn.html" (dict "key" "url-retirement:warn:register-url-no-page" "message" "[url-retirement] register-url.html was called without a page: pass (dict \"page\" . \"url\" $url). No URL was recorded.") -}} {{- else -}} {{/* Both keys are collected raw and validated as ELEMENTS below, because a caller that passes one URL where a list belongs -- or the reverse -- is the plausible mistake, and `range` over a string raises while `with` treats a table as present. */}} {{- $raw := slice -}} {{- if ne .url nil -}} {{- $raw = $raw | append .url -}} {{- end -}} {{- $many := .urls -}} {{- if reflect.IsSlice $many -}} {{- range $many -}} {{- $raw = $raw | append . -}} {{- end -}} {{- else if ne $many nil -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-many-shape:%v" $many) "message" (printf "[url-retirement] Ignoring the .urls value %q passed to register-url.html on %s: it expects a list of URLs, and one URL goes in .url instead. Nothing it names is listed in /url-manifest.txt." (printf "%v" $many) $page.Path)) -}} {{- end -}} {{/* Reported only when NEITHER key was supplied. A caller that passed a misshapen .urls has already been told what was wrong with it, and being told a second time that it passed nothing would send it looking for a different mistake. */}} {{- if and (eq .url nil) (eq .urls nil) -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-no-url:%v" $page.Path) "message" (printf "[url-retirement] register-url.html was called on %s with neither .url nor .urls: pass (dict \"page\" . \"url\" $url), or .urls for several. No URL was recorded for this page." $page.Path)) -}} {{- end -}} {{/* An entry is rejected at the edge rather than downstream, because lib/prefix-url.html documents a server-relative path as its precondition: a table reaches the file as `map[...]`, a bare word as `/docsno-slash`, and an absolute URL as `/docshttps://elsewhere.example/`, in a document compared byte for byte against production. */}} {{- range $u := $raw -}} {{- $url := "" -}} {{- if or (reflect.IsMap $u) (reflect.IsSlice $u) (eq (printf "%T" $u) "bool") -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-shape:%v" $u) "message" (printf "[url-retirement] Ignoring the URL %q passed to register-url.html on %s: a URL is one path written as a single value. It is not listed in /url-manifest.txt." (printf "%v" $u) $page.Path)) -}} {{- else -}} {{- $cand := trim (printf "%v" $u) " \t\n\r" -}} {{- if not $cand -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-empty:%v" $page.Path) "message" (printf "[url-retirement] Ignoring an empty URL passed to register-url.html on %s. A resource whose URL is empty was never published, so registering it would name a path nothing serves." $page.Path)) -}} {{- else if not (hasPrefix $cand "/") -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-path:%s" $cand) "message" (printf "[url-retirement] Ignoring the URL %q passed to register-url.html on %s: a registered URL is server-relative and must start with \"/\". Pass .RelPermalink rather than .Permalink. It is not listed in /url-manifest.txt." $cand $page.Path)) -}} {{- else -}} {{- $url = $cand -}} {{- end -}} {{- end -}} {{- with $url -}} {{- partial "url-retirement/lib/record-url.html" (dict "page" $page "url" .) -}} {{- end -}} {{- end -}} {{- end -}}
