{{/* url-retirement/register-url.html -- PUBLIC. Purpose: records a URL this build publishes that no walk of the page graph can reach, so /url-manifest.txt lists it. Call it from the template that PUBLISHES the URL, guarded so a site without this module pays nothing: {{ $page := . }} {{ with resources.Get "js/sw.js" }} {{ with (. | js.Build $opts).RelPermalink }} {{ if templates.Exists "_partials/url-retirement/register-url.html" }} {{ partial "url-retirement/register-url.html" (dict "page" $page "url" .) }} {{ end }} {{ end }} {{ end }} The page is captured BEFORE the `with` blocks because each of them rebinds the dot to the resource. The guard takes a path under layouts/ WITH the .html suffix, which `partial` itself does not need, and the pre-v0.146 `partials/` spelling silently returns false. Why the publisher has to make this call. The manifest is built by crossing every page in site.Pages with its output formats, and several things a build really publishes are in neither: a file the asset pipeline wrote, which is a Resource rather than a Page and exists only where a template read its URL; a page kept out of every page collection by build.list = never, which is how a module ships a page a site never lists; a file copied verbatim from static/, which Hugo exposes to no template at all. Nothing can enumerate those from outside, and the omission is the SILENT direction for this document -- a URL missing from the registry is one whose disappearance from production the coverage check can never report. The publisher is the only party that knows, so this is where it says so. REGISTER WHAT THE BUILD REALLY WROTE, not what it intends to write. Every other line in the manifest is evidence a file exists; a registration is the one arrival path that can ADD a line no file backs, which would put a URL production answers 404 for into a document meant to be diffed against production. Reading a Resource's .RelPermalink is what materializes it, so register the URL the read returned, at the point it returned it, and not from a branch that might not publish. DO NOT REGISTER A CONTENT-ADDRESSED URL -- a fingerprinted script, a processed image, anything carrying a hash of its own contents. Such a URL changes whenever its source does, by design, so listing it makes every rebuild report a retirement and a new URL in a file whose only use is showing what genuinely changed. The same goes for anything a development build publishes and a production build does not, such as a source map: a manifest that is structurally unequal to production's cannot be compared with it. PASS .resource AND THAT RULE IS APPLIED FOR YOU. A caller that has a Resource rather than a bare URL hands it over instead, and this partial registers its .RelPermalink only when the resource is published under the name it came in with -- when the base name of .RelPermalink is the base name of .Name. A Hugo derivative is published under a name carrying a hash of its own contents (measured at v0.164.0: a composed card whose source is card-base.png publishes as card-base_hu_.png, while .Name still reports the source's name), so the two come apart exactly where the URL is content-addressed. Pass a resource whenever you have one: the check observes the name the build really wrote rather than trusting a caller to know how its resource was produced, which is knowledge a caller often does not have -- an image handed to a module by a hook was processed somewhere the module never saw. A resource that fails that check is skipped SILENTLY, alone among this partial's refusals. It is not a mistake to be told about: a module resolving images gets derived ones as a matter of course, and warning per page per image would bury the diagnostics that do mean something under the ordinary case. ORDERING. Hugo renders one output format at a time within a language, positive weights ascending and then every zero-weight format, so /url-manifest.txt at weight 100 sees registrations made during any pass that renders before it and none made afterwards. The html format is weight 10, so an html-pass template is always in time; a format carrying no weight renders after every weighted one, so a registration made from its own template is not. A registration that arrives too late is refused with a warning naming the URL rather than silently dropped, but it is still not recorded. So this partial is for a template that KNOWS which pass reaches it. Where the publication happens in whichever pass reaches a shared resolution first -- which is a property of the consuming site's configuration rather than of the module -- registering is the wrong shape however carefully it is placed, and the format's owner answers a url-retirement/writes/.html hook instead, which the manifest asks during its own pass. lib/writes.html carries the contract and the measurement behind it. Expected context (dict): - .page (Page) The page being rendered; names the language whose manifest the URL belongs to. - .url (string) One server-relative URL, beginning with "/". - .urls (slice) Several of them, when one call publishes more than one. - .resource One Resource, whose URL is registered only when it is published under its own source name. Pass any one key, or several. Return value: none. Side effect: the URLs are recorded for this build. */}} {{- /* The context is read for named keys, so a caller that passed the page itself -- the shape every other partial in this module takes -- would raise out of a module rather than degrade, which is the one thing this module never does to a consuming build. Every action in this file is whitespace-trimmed, this comment included: the partial renders into whatever the caller is rendering, and one stray newline in a plain-text output format is the difference between Hugo writing no file and writing one. */ -}} {{- if not (reflect.IsMap .) -}} {{- partial "url-retirement/lib/warn.html" (dict "key" "url-retirement:warn:register-url-no-dict" "message" (printf "[url-retirement] register-url.html was called with a %s instead of a context dict: pass (dict \"page\" . \"url\" $url). No URL was recorded." (printf "%T" .))) -}} {{- else if not (reflect.IsPage .page) -}} {{- partial "url-retirement/lib/warn.html" (dict "key" "url-retirement:warn:register-url-no-page" "message" "[url-retirement] register-url.html was called without a page: pass (dict \"page\" . \"url\" $url). No URL was recorded.") -}} {{- else -}} {{- $page := .page -}} {{/* Each candidate is wrapped rather than appended raw, because `append` flattens a slice argument into its elements: a list passed to .url would otherwise be silently accepted as several URLs, which is the opposite of the rejection the shape check exists to make. */}} {{- $candidates := slice -}} {{- if ne .url nil -}} {{- $candidates = $candidates | append (dict "v" .url) -}} {{- end -}} {{- $many := .urls -}} {{- if reflect.IsSlice $many -}} {{- range $many -}} {{- $candidates = $candidates | append (dict "v" .) -}} {{- end -}} {{- else if ne $many nil -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-many-shape:%v" $many) "message" (printf "[url-retirement] Ignoring the .urls value %q passed to register-url.html on %s: it expects a list of URLs, and one URL goes in .url instead. Nothing it names is listed in /url-manifest.txt." (printf "%v" $many) $page.Path)) -}} {{- end -}} {{/* A Resource is turned into a candidate here rather than by the caller, so the content-addressed rule is applied once in this module instead of being restated at every publish site that has one. Reading .RelPermalink is what publishes the resource, and the caller has already read a URL off it -- that read is why there is anything to register. */}} {{- with .resource -}} {{- $published := .RelPermalink -}} {{- if eq (path.Base $published) (path.Base .Name) -}} {{- $candidates = $candidates | append (dict "v" $published) -}} {{- end -}} {{- end -}} {{/* Reported only when NO key was supplied. A caller that passed a misshapen .urls has already been told what was wrong with it, and being told a second time that it passed nothing would send it looking for a different mistake. */}} {{- if and (eq .url nil) (eq .urls nil) (eq .resource nil) -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-no-url:%v" $page.Path) "message" (printf "[url-retirement] register-url.html was called on %s with none of .url, .urls or .resource: pass (dict \"page\" . \"url\" $url), .urls for several, or .resource when you have the Resource itself. No URL was recorded for this page." $page.Path)) -}} {{- end -}} {{/* The rule is lib/url-shape.html's, shared with the configured `extra` and `exclude` entries so a URL registered and a URL configured are held to one standard; only the wording is this file's, because the audience is whoever wrote the CALL rather than whoever wrote the configuration. */}} {{- $reasons := dict "shape" "a URL is one path written as a single value" "relative" "a registered URL is server-relative and must start with \"/\". Pass .RelPermalink rather than .Permalink" "network-path" "a value beginning with \"//\" is a protocol-relative URL naming another host, not a path this site serves" "whitespace" "a registered URL may not contain whitespace, because /url-manifest.txt carries one URL per line" -}} {{- range $c := $candidates -}} {{- $checked := partial "url-retirement/lib/url-shape.html" (dict "value" $c.v) -}} {{- with $checked.fault -}} {{- if eq . "empty" -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-empty:%v" $page.Path) "message" (printf "[url-retirement] Ignoring an empty URL passed to register-url.html on %s. A resource whose URL is empty was never published, so registering it would name a path nothing serves." $page.Path)) -}} {{- else -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:register-url-%s:%v" . $c.v) "message" (printf "[url-retirement] Ignoring the URL %q passed to register-url.html on %s: %s. It is not listed in /url-manifest.txt." (printf "%v" $c.v) $page.Path (index $reasons .))) -}} {{- end -}} {{- end -}} {{- with $checked.path -}} {{- partial "url-retirement/lib/record-url.html" (dict "page" $page "url" .) -}} {{- end -}} {{- end -}} {{- end -}}
