{{/* url-retirement/redirects/rules.html -- INTERNAL (resolver tier). Purpose: assembles the generated half of /_redirects -- the alias rules, the first-pager rules and the default site's root redirect -- into ONE set, sorted by source path and checked for conflicts. The three producers are separate because their evidence is: an alias is content a page carries, a pager is a URL the site registered while rendering, and the root redirect is the shape the language configuration puts the site in. Their OUTPUT is not separate, because both hosts that read this file take the first matching rule, so two rules claiming one retired URL mean one of them silently never receives its traffic. A conflict walk inside any one producer would see part of the file and miss exactly the cases worth catching: a page aliased to a URL that is also some list's first pager, or to the site root a default-language subdirectory retires. Sorting for the same reason happens here and once. Concatenating sorted parts would leave the file unsorted, and sorted order is what puts claimants of one URL next to each other so a single walk finds them. The conflict walk needs no multihost arm of its own, and the reason is worth stating because a reader looks for one here. A conflict is two rules claiming one source path IN ONE FILE, and on a multihost site each host publishes its own; the producers narrow to the rendering host accordingly, so this set never mixes two hosts and two hosts retiring the same path to their own separate replacements are not in conflict at all. Context (dict): - .page (Page) The page rendering the document, for diagnostics. - .cfg (dict) Resolved configuration from url-retirement/config.html. Return value: slice of dicts with `from`, `to` and `status`, sorted by `from`. One terminal return. */}} {{- $page := .page -}} {{- $cfg := .cfg -}} {{- $rules := slice -}} {{/* Appended one rule at a time rather than slice by slice: `append` flattens a slice argument into a target whose element type matches, but the target here starts empty, and an empty slice has no element type to match. */}} {{- range $r := partial "url-retirement/redirects/aliases.html" (dict "page" $page "cfg" $cfg) -}} {{- $rules = $rules | append $r -}} {{- end -}} {{- range $r := partial "url-retirement/redirects/pagers.html" (dict "page" $page "cfg" $cfg) -}} {{- $rules = $rules | append $r -}} {{- end -}} {{- range $r := partial "url-retirement/redirects/language-root.html" (dict "cfg" $cfg) -}} {{- $rules = $rules | append $r -}} {{- end -}} {{- $sorted := slice -}} {{- with $rules -}} {{- $sorted = sort . "from" -}} {{- end -}} {{/* Two pages claiming the same retired URL is a content mistake this file cannot resolve: both hosts take the first matching rule, so every page but one silently never receives its traffic. Sorted order puts the claimants adjacent, so one walk finds them all. The diagnostic names EVERY claimant in one message rather than one pair per message, because the dedup key can only be the retired URL itself: three pages sharing an alias produce two adjacent pairs whose keys would collide, and the second pair -- a different page -- would be suppressed as a duplicate. Collecting first and reporting once is the same shape lines.html uses for a configuration that diverges per language. */}} {{- $contested := slice -}} {{- $previous := dict -}} {{- range $r := $sorted -}} {{- if and $previous (eq (index $previous "from" | default "") $r.from) (ne (index $previous "to" | default "") $r.to) -}} {{- $contested = $contested | append $r.from -}} {{- end -}} {{- $previous = $r -}} {{- end -}} {{- range $from := uniq $contested -}} {{- $targets := slice -}} {{- range $r := $sorted -}} {{- if eq $r.from $from -}}{{- $targets = $targets | append $r.to -}}{{- end -}} {{- end -}} {{- partial "url-retirement/lib/warn.html" (dict "key" (printf "url-retirement:warn:conflicting-url:%s" $from) "message" (printf "[url-retirement] The retired URL %q is claimed by more than one page (%s). The host takes the first matching rule, so only one of them will ever receive that traffic." $from (delimit (sort (uniq $targets)) ", "))) -}} {{- end -}} {{- return $sorted -}}
