{{/* url-retirement/redirects/aliases.html -- INTERNAL (resolver tier). Purpose: turns every alias of every page of every language into rules. Every language is walked through `hugo.Sites` rather than the current site alone, because /_redirects is published once at the site root and has to describe the whole deployment. Two older spellings of this walk are gone: `.Site.AllPages` was deprecated in Hugo v0.156.0, and `.Page.Sites` in the same release. The page a rule points AT is captured with `{{ $p := . }}`, never read as `$`. Inside a range, `$` stays bound to the template's top-level context -- the home page rendering the document -- so a rule written with `$.RelPermalink` sends every retired URL to the home page. The example in Hugo's own method documentation is written that way; a build proved what it emits. Whitespace ends a field in this file format, so an alias or a target containing any is fatal rather than degraded: Hugo neither sanitizes nor rejects such a path, and the alternative to failing is publishing a rule that redirects somewhere nobody asked for. The rules come back UNSORTED and unchecked for conflicts. Both belong to redirects/rules.html, which owns the merged set: an alias and a generated pager rule can claim the same retired URL, and a conflict walk that ran here would see only half the file. Context (dict): - .page (Page) The page rendering the document, for diagnostics. - .cfg (dict) Resolved configuration from url-retirement/config.html. Return value: slice of dicts with `from`, `to` and `status`. One terminal return. */}} {{- $cfg := .cfg -}} {{- $status := $cfg.redirects.status -}} {{- $mode := $cfg.redirects.trailing_slash -}} {{- $rules := slice -}} {{- range $site := hugo.Sites -}} {{- $base := strings.TrimSuffix "/" (urls.Parse $site.BaseURL).Path -}} {{- range $p := $site.Pages -}} {{- with $p.Aliases -}} {{- $target := partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" $p.RelPermalink) -}} {{- if findRE `\s` $target -}} {{- errorf "[url-retirement] The URL of %s is %q, which contains whitespace and cannot be written as a redirect target. Give the page a URL without spaces, or remove its aliases." $p.Path $target -}} {{- end -}} {{- range $alias := . -}} {{- if findRE `\s` $alias -}} {{- errorf "[url-retirement] Alias %q on %s contains whitespace, which ends a field in the _redirects format. Remove the whitespace from the alias." $alias $p.Path -}} {{- else -}} {{- $from := partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" $alias) -}} {{- range $spelling := partial "url-retirement/lib/spellings.html" (dict "url" $from "mode" $mode) -}} {{- $rules = $rules | append (dict "from" $spelling "to" $target "status" $status) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $rules -}}
