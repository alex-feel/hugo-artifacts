{{/* url-retirement/manifest/lines.html -- INTERNAL (document tier). Purpose: builds every line of /url-manifest.txt for one language -- a `#` comment header, then every URL the build publishes AND a host serves, sorted, one per line -- and RETURNS them. It prints nothing; see redirects/lines.html for why a partial in this module never emits into a plain-text document. What it lists: every page of this language crossed with its output formats (so an RSS feed, a Markdown twin and a JSON representation each count as the published URLs they are), every URL registered for this language -- pager URLs through register-pagers.html, and whatever a module registered through register-url.html for what it published outside the page graph -- every URL a format's owner names when this document ASKS it what else that format wrote, through lib/writes.html, and whatever url_retirement.manifest.extra names. Two directions, and the difference is which party can guarantee the timing. A template reached from the html pass registers what it published and is always in time. A format whose side files are published from whichever caller reaches its resolution first cannot promise that, so this document asks instead, in its own pass, where an answer cannot be late. lib/writes.html carries the measurement that settled which case is which. What the page walk cannot REACH, and the header says so, is a file copied verbatim from static/, whatever the asset pipeline publishes (a script, a processed image), a page kept out of every page collection by build.list = never -- which is how a module ships a page a site never lists, so `.Site.Pages` cannot see it -- and the site-level documents whose publication is decided by settings no template can read (sitemap.xml, robots.txt, 404.html). Those reach this file only by registration, from the template that published them, or through `extra` when the site owns them. What it DELIBERATELY leaves out, and also says so in its own header: the redirect map this module renders. Hugo publishes it, so a walk of the build tree finds it, but the hosts that read it consume it at deploy time and serve it to nobody -- measured against a live Cloudflare Pages site, where /_redirects answers 404 while /sitemap.xml and /robots.txt answer 200. This document exists to be compared against what production serves, so a path production never serves is a line that is wrong for the one use the file has, and the module is the one party that knows the document is a host control file rather than a page. A consumer's own control file rendered through its own output format is the same case with a different owner, and url_retirement.manifest.exclude is how the consumer names it. What it does NOT take on trust: .OutputFormats, which reports the formats CONFIGURED for a page rather than the documents published for it. Hugo decides publication on the rendered BYTE LENGTH -- a template emitting the empty string publishes no file -- and reports that nowhere: the format stays listed, .RelPermalink keeps resolving to the path nothing was written to, and the log is silent at every level including --logLevel debug. Hugo's "found no layout file for ..." warning does not cover it either; measured at v0.164.0 and at v0.160.0, that one fires only for a format with no template of a matching SUFFIX, and Hugo silently borrows another template when one exists. So lib/publishes.html asks the format's owner, and lib/page-renders.html drops a page Hugo writes no document for at all. A format nobody answers for is listed as wired, which the header says. Context (dict): - .page (Page) The home page rendering the document. Return value: slice of strings, one line each. Empty when the module or the document is switched off. One terminal return. */}} {{- $page := .page -}} {{- $cfg := partial "url-retirement/config.html" (dict "page" $page) -}} {{- $lines := slice -}} {{- if and $cfg.enable $cfg.manifest.enable -}} {{/* Every URL is normalized through lib/prefix-url.html so a subpath site and a canonified one publish the same manifest: under canonifyURLs, .RelPermalink stops carrying the baseURL's path segment. */}} {{- $base := strings.TrimSuffix "/" (urls.Parse $page.Site.BaseURL).Path -}} {{- $urls := slice -}} {{- range $p := $page.Site.Pages -}} {{/* A page Hugo renders no document for contributes nothing in either mode, however much of it .OutputFormats and .RelPermalink still report. */}} {{- if partial "url-retirement/lib/page-renders.html" (dict "page" $p) -}} {{/* The module's own redirect map is skipped rather than listed: every host it targets consumes that file at deploy time and serves nothing at its path, so listing it puts a URL nobody can fetch in a document whose purpose is to be compared against what production serves. The name is lowercased before comparing so the case Hugo reports for a format cannot decide whether the line is emitted. That skip answers "published but never served"; lib/publishes.html answers the different question of whether anything was published at all. This walk runs in BOTH modes, because the two questions asked inside it are not the same question. Whether to list a page's own per-format URLs is what output_formats governs; what ELSE a format wrote is a fact about the build that the setting has no opinion on, and a site that lists one URL per page still serves the files its formats published beside their documents. */}} {{- range $f := $p.OutputFormats -}} {{- if ne (lower $f.Name) "redirects" -}} {{- if partial "url-retirement/lib/publishes.html" (dict "page" $p "format" $f) -}} {{- if $cfg.manifest.output_formats -}} {{- with $f.RelPermalink -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{- end -}} {{/* Asked here, in this document's own pass, rather than waiting to be told: a format's side files are published wherever that format's owner happens to be reached from, which is a property of the consuming site's configuration. See lib/writes.html. */}} {{- range partial "url-retirement/lib/writes.html" (dict "page" $p "format" $f) -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* Through lib/page-url.html rather than off .RelPermalink, because this document renders in a format that is not permalinkable: on a site that lists this module's formats ahead of html, a page asked for its own URL here answers with the manifest's. Outside the publishes gate above, because this line is the PAGE rather than any one format's document, and a page Hugo renders at all has a URL. */}} {{- if not $cfg.manifest.output_formats -}} {{- with partial "url-retirement/lib/page-url.html" (dict "page" $p) -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* Everything registered during this language's html pass: the pager URLs the site's own list templates recorded, and the URLs a module registered for what it published outside the page graph. The store key carries the language because the store is build-global: without it, the second language's manifest would republish the first language's URLs as its own. no-concurrent-writer: every registration for this language is written while its pages render, and this document is the only one in the urlmanifest pass, which runs after them; Hugo renders one language completely before starting the next, so no other language is writing either. Both orderings are measured rather than documented, which is what this marker exists to make visible if either ever changes. */}} {{- range hugo.Store.GetSortedMapValues (printf "url-retirement:registered:%s" $cfg.lang) -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" (printf "%v" .))) -}} {{- end -}} {{/* Held before the `extra` list joins it, because it is the answer to "would this URL be here anyway" -- which is the question manifest/ redundant-extra.html asks below, once every language has answered it. */}} {{- $fromBuild := $urls -}} {{- range $cfg.manifest.extra -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{/* Subtracted from the FINISHED set, so one entry reaches a URL however it arrived -- as a page's output format, as a registered pager, as an `extra` line -- and a path named in both `extra` and `exclude` is left out. What it exists for is a control file the SITE renders through an output format of its own, a `_headers` map or a `_routes.json`: the same published-but-never-served case as the redirect map skipped above, with an owner the module cannot enumerate. An entry matching nothing is deliberately NOT reported. Every language renders its own manifest, so a path under one language's prefix matches nothing in another language's file, and a per-language diagnostic would fire on every multilingual site that uses the key exactly right. An `extra` entry meets the same objection and answers it rather than avoiding it -- redundant-extra.html waits for every language that names the entry -- but an unmatched `exclude` entry is not the same evidence: matching nothing is what a correctly scoped entry looks like from the other language, while a URL the build reaches on its own is a fact about the build that holds whichever language is asking. */}} {{- $excluded := slice -}} {{- range $cfg.manifest.exclude -}} {{- $excluded = $excluded | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{/* Asked after `excluded` is normalized and before the lines are assembled: the diagnostic skips an entry the site also excludes, and it changes no line of the document either way. */}} {{- partial "url-retirement/manifest/redundant-extra.html" (dict "cfg" $cfg "base" $base "from_build" $fromBuild "excluded" $excluded) -}} {{- $sorted := slice -}} {{- with $urls -}} {{- $sorted = uniq (sort .) -}} {{- end -}} {{- with $excluded -}} {{- $kept := slice -}} {{- range $sorted -}} {{- if not (in $excluded .) -}} {{- $kept = $kept | append . -}} {{- end -}} {{- end -}} {{- $sorted = $kept -}} {{- end -}} {{/* A sibling is named only when that language will actually publish one. Two independent things decide that: the format has to be wired onto that language's home page, and that language's own configuration has to leave the manifest switched on -- a per-language `manifest.enable = false` is invisible in the format wiring. Naming a file that was never written breaks the one discovery mechanism this header exists to provide, so both are checked rather than the cheaper one. A sibling on ANOTHER HOST is named absolutely, and only .Permalink can do it. Under multihost every language has its own baseURL and its own publish root, so a foreign manifest's .RelPermalink is /url-manifest.txt -- measured at Hugo v0.164.0, and identical to the path this host serves its OWN manifest at, which turns the one line that exists to point somewhere else into a line pointing back here. .Permalink carries that language's host, which is the only form a checker starting on this host can follow. */}} {{- $siblings := slice -}} {{- range $s := hugo.Sites -}} {{- if ne $s.Language.Name $cfg.lang -}} {{- with $s.Home.OutputFormats.Get "urlmanifest" -}} {{- $scfg := partial "url-retirement/config.html" (dict "page" $s.Home) -}} {{- if and $scfg.enable $scfg.manifest.enable -}} {{- if hugo.IsMultihost -}} {{- $siblings = $siblings | append .Permalink -}} {{- else -}} {{- $siblings = $siblings | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .RelPermalink)) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- $lines = slice (printf "# Every URL this build publishes and a host serves, for language %q, sorted, one per line." $cfg.lang) "# Generated by the url-retirement Hugo module. Lines starting with # are comments." "# A URL no page carries is here only because something registered it:" "# a file copied verbatim from static/, anything the asset pipeline" "# publishes, a page kept out of every page collection by" "# build.list = never, and any document whose publication is decided by a" "# setting no template can read. The module that publishes one registers" "# it, or answers for it when this document asks the owner of an output" "# format what else that format wrote; name the rest in" "# url_retirement.manifest.extra. A content-addressed" "# URL is left out on purpose: a fingerprinted name changes with its own" "# contents, so listing it would report a retirement on every rebuild." "# Also not listed: the redirect map this module publishes, which every" "# host that reads it consumes at deploy time and serves at no URL, and" "# whatever url_retirement.manifest.exclude names." "# One class can still be over-listed: an output format renders nothing" "# for some pages and Hugo publishes no file, which it reports nowhere," "# so the format's owner answers for it through a publication hook. A" "# format nobody answers for is listed as wired." -}} {{- with $siblings -}} {{- $lines = $lines | append (printf "# Other languages: %s" (delimit . ", ")) -}} {{- end -}} {{- $lines = $lines | append (printf "# %d URLs follow." (len $sorted)) -}} {{- with $sorted -}} {{- $lines = $lines | append . -}} {{- end -}} {{/* The set is closed. Anything registered for this language from here on reaches a document already written, so lib/record-url.html reads this sentinel and refuses such a registration with a warning naming the URL rather than accepting it into a map nothing will read again. It is set LAST, after the lines are assembled, so a registration made while this document was still collecting is never mistaken for a late one; and only inside this branch, because a language publishing no manifest loses nothing by a late registration and would only be told off for it. */}} {{- hugo.Store.Set (printf "url-retirement:manifest-rendered:%s" $cfg.lang) true -}} {{- end -}} {{- return $lines -}}
