{{/* url-retirement/manifest/lines.html -- INTERNAL (document tier). Purpose: builds every line of /url-manifest.txt for one language -- a `#` comment header, then every URL the build publishes AND a host serves, sorted, one per line -- and RETURNS them. It prints nothing; see redirects/lines.html for why a partial in this module never emits into a plain-text document. What it lists: every page of this language crossed with its output formats (so an RSS feed, a Markdown twin and a JSON representation each count as the published URLs they are), every pager URL the site registered through register-pagers.html, and whatever url_retirement.manifest.extra names. What it cannot list, and says so in its own header, is everything no template can enumerate: files copied verbatim from static/, whatever the asset pipeline publishes (a fingerprinted script, a processed image), a page kept out of every page collection by build.list = never -- which is how a module ships a page a site never lists, so `.Site.Pages` cannot see it -- and the site-level documents whose publication is decided by settings no template can read (sitemap.xml, robots.txt, 404.html). `extra` exists for exactly those. What it DELIBERATELY leaves out, and also says so in its own header: the redirect map this module renders. Hugo publishes it, so a walk of the build tree finds it, but the hosts that read it consume it at deploy time and serve it to nobody -- measured against a live Cloudflare Pages site, where /_redirects answers 404 while /sitemap.xml and /robots.txt answer 200. This document exists to be compared against what production serves, so a path production never serves is a line that is wrong for the one use the file has, and the module is the one party that knows the document is a host control file rather than a page. A consumer's own control file rendered through its own output format is the same case with a different owner, and url_retirement.manifest.exclude is how the consumer names it. What it does NOT take on trust: .OutputFormats, which reports the formats CONFIGURED for a page rather than the documents published for it. Hugo decides publication on the rendered BYTE LENGTH -- a template emitting the empty string publishes no file -- and reports that nowhere: the format stays listed, .RelPermalink keeps resolving to the path nothing was written to, and the log is silent at every level including --logLevel debug. Hugo's "found no layout file for ..." warning does not cover it either; measured at v0.164.0 and at v0.160.0, that one fires only for a format with no template of a matching SUFFIX, and Hugo silently borrows another template when one exists. So lib/publishes.html asks the format's owner, and lib/page-renders.html drops a page Hugo writes no document for at all. A format nobody answers for is listed as wired, which the header says. Context (dict): - .page (Page) The home page rendering the document. Return value: slice of strings, one line each. Empty when the module or the document is switched off. One terminal return. */}} {{- $page := .page -}} {{- $cfg := partial "url-retirement/config.html" (dict "page" $page) -}} {{- $lines := slice -}} {{- if and $cfg.enable $cfg.manifest.enable -}} {{/* Every URL is normalized through lib/prefix-url.html so a subpath site and a canonified one publish the same manifest: under canonifyURLs, .RelPermalink stops carrying the baseURL's path segment. */}} {{- $base := strings.TrimSuffix "/" (urls.Parse $page.Site.BaseURL).Path -}} {{- $urls := slice -}} {{- range $p := $page.Site.Pages -}} {{/* A page Hugo renders no document for contributes nothing in either mode, however much of it .OutputFormats and .RelPermalink still report. */}} {{- if partial "url-retirement/lib/page-renders.html" (dict "page" $p) -}} {{- if $cfg.manifest.output_formats -}} {{/* The module's own redirect map is skipped rather than listed: every host it targets consumes that file at deploy time and serves nothing at its path, so listing it puts a URL nobody can fetch in a document whose purpose is to be compared against what production serves. The name is lowercased before comparing so the case Hugo reports for a format cannot decide whether the line is emitted. That skip answers "published but never served"; lib/publishes.html answers the different question of whether anything was published at all. */}} {{- range $f := $p.OutputFormats -}} {{- if ne (lower $f.Name) "redirects" -}} {{- if partial "url-retirement/lib/publishes.html" (dict "page" $p "format" $f) -}} {{- with $f.RelPermalink -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- else -}} {{/* Through lib/page-url.html rather than off .RelPermalink, because this document renders in a format that is not permalinkable: on a site that lists this module's formats ahead of html, a page asked for its own URL here answers with the manifest's. */}} {{- with partial "url-retirement/lib/page-url.html" (dict "page" $p) -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* Pagers, recorded during the html pass by the site's own list templates. The store key carries the language because the store is build-global: without it, the second language's manifest would republish the first language's pager URLs as its own. */}} {{- range hugo.Store.GetSortedMapValues (printf "url-retirement:pagers:%s" $cfg.lang) -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" (printf "%v" .))) -}} {{- end -}} {{- range $cfg.manifest.extra -}} {{- $urls = $urls | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{/* Subtracted from the FINISHED set, so one entry reaches a URL however it arrived -- as a page's output format, as a registered pager, as an `extra` line -- and a path named in both `extra` and `exclude` is left out. What it exists for is a control file the SITE renders through an output format of its own, a `_headers` map or a `_routes.json`: the same published-but-never-served case as the redirect map skipped above, with an owner the module cannot enumerate. An entry matching nothing is deliberately NOT reported. Every language renders its own manifest, so a path under one language's prefix matches nothing in another language's file, and a per-language diagnostic would fire on every multilingual site that uses the key exactly right. */}} {{- $excluded := slice -}} {{- range $cfg.manifest.exclude -}} {{- $excluded = $excluded | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .)) -}} {{- end -}} {{- $sorted := slice -}} {{- with $urls -}} {{- $sorted = uniq (sort .) -}} {{- end -}} {{- with $excluded -}} {{- $kept := slice -}} {{- range $sorted -}} {{- if not (in $excluded .) -}} {{- $kept = $kept | append . -}} {{- end -}} {{- end -}} {{- $sorted = $kept -}} {{- end -}} {{/* A sibling is named only when that language will actually publish one. Two independent things decide that: the format has to be wired onto that language's home page, and that language's own configuration has to leave the manifest switched on -- a per-language `manifest.enable = false` is invisible in the format wiring. Naming a file that was never written breaks the one discovery mechanism this header exists to provide, so both are checked rather than the cheaper one. A sibling on ANOTHER HOST is named absolutely, and only .Permalink can do it. Under multihost every language has its own baseURL and its own publish root, so a foreign manifest's .RelPermalink is /url-manifest.txt -- measured at Hugo v0.164.0, and identical to the path this host serves its OWN manifest at, which turns the one line that exists to point somewhere else into a line pointing back here. .Permalink carries that language's host, which is the only form a checker starting on this host can follow. */}} {{- $siblings := slice -}} {{- range $s := hugo.Sites -}} {{- if ne $s.Language.Name $cfg.lang -}} {{- with $s.Home.OutputFormats.Get "urlmanifest" -}} {{- $scfg := partial "url-retirement/config.html" (dict "page" $s.Home) -}} {{- if and $scfg.enable $scfg.manifest.enable -}} {{- if hugo.IsMultihost -}} {{- $siblings = $siblings | append .Permalink -}} {{- else -}} {{- $siblings = $siblings | append (partial "url-retirement/lib/prefix-url.html" (dict "base" $base "url" .RelPermalink)) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- $lines = slice (printf "# Every URL this build publishes and a host serves, for language %q, sorted, one per line." $cfg.lang) "# Generated by the url-retirement Hugo module. Lines starting with # are comments." "# Not listed, because no template can enumerate them: files copied" "# verbatim from static/, anything the asset pipeline publishes (a" "# fingerprinted script, a processed image), a page kept out of every page" "# collection by build.list = never, and any document whose publication is" "# decided by a setting no template can read. Also not listed: the" "# redirect map this module publishes, which every host that reads it" "# consumes at deploy time and serves at no URL, and whatever" "# url_retirement.manifest.exclude names. Name what is missing in" "# url_retirement.manifest.extra." "# One class can still be over-listed: an output format renders nothing" "# for some pages and Hugo publishes no file, which it reports nowhere," "# so the format's owner answers for it through a publication hook. A" "# format nobody answers for is listed as wired." -}} {{- with $siblings -}} {{- $lines = $lines | append (printf "# Other languages: %s" (delimit . ", ")) -}} {{- end -}} {{- $lines = $lines | append (printf "# %d URLs follow." (len $sorted)) -}} {{- with $sorted -}} {{- $lines = $lines | append . -}} {{- end -}} {{- end -}} {{- return $lines -}}
