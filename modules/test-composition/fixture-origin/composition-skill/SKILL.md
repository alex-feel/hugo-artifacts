# Composition skill

This skill exists so that the agent-readiness module publishes an artifact no walk of the page graph can reach, in a build that also holds the url-retirement module.

The body names no sibling file of any kind, so the supporting-file detector must stay silent about it, and a warning about this entry is a defect in the detector rather than a fact about the skill.
