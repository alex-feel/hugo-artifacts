{{/* agent-readiness/facts.html -- renderer (RENDERER tier). Purpose: render /about.md, the aggregated facts document -- the one-fetch answer to "who is this, what can they do, what have they built, and how do I reach them". Why this surface exists at all. Per-page twins answer "what does this page say". llms.txt is a link index and carries no facts. And a home-page twin inherits whatever truncation the home template applies, because a typical home page renders first-N previews. None of the three answers the question in ONE fetch, complete. This document does, and it is assembly rather than duplication: it lists facts that already exist in front matter, never page bodies (that would be llms-full.txt, a declared non-goal). COMPLETE BY CONSTRUCTION: a facts section has NO `limit` key, by design. A truncated facts index answers the question wrongly while appearing to answer it, which is worse than not shipping one. The fixture asserts that each section's top-level bullet count numerically EQUALS the shared filter's page count for that section. It fabricates nothing. Every value originates in front matter or config that already exists; there is no default text for an absent field and no inferred value anywhere. The identity rows and the contact channels are read from REAL content pages named in config rather than retyped into config, so the document cannot drift away from the site it describes. The `present` sentinel is rendered here as the prose it is, deliberately unlike the Markdown twin front matter, which omits it: this document is read as prose, and "present" is a true and useful thing to say about an open-ended range. Structure: H1, summary, identity block, one H2 per configured section, contact block, trailing pointer section. The document is line-oriented, so every interpolated value goes through lib/inline.html -- or lib/markdown-link.html when it lands inside a link -- before it joins its line: a value-borne line break is a structure change here, not text, and an unescaped bracket in a link text or parenthesis in a destination ends the link's own syntax early. Expected context (dict): - .page (Page) - The home page. - .cfg (dict) - The resolved config from agent-readiness/config.html. Return value: none. This partial renders. */}} {{- $page := .page -}} {{- $cfg := .cfg -}} {{- $facts := $cfg.facts -}} {{- if and $cfg.enable $facts.enable -}} {{- $lines := slice -}} {{/* 1. Exactly one H1. */}} {{- $lines = $lines | append (printf "# %s" (partial "agent-readiness/lib/inline.html" ($facts.title | default $cfg.i18n.facts_title | default site.Title))) -}} {{/* 2. Optional one-line summary. */}} {{- with $facts.summary -}} {{- $lines = $lines | append "" | append (printf "> %s" (partial "agent-readiness/lib/inline.html" .)) -}} {{- end -}} {{/* 3. Identity block, read from a real content page so it cannot drift. A row whose key is absent from that page is omitted SILENTLY: a missing optional fact is not an error, and inventing a placeholder would be fabrication. */}} {{- $identity := $facts.identity | default dict -}} {{- $identityRows := $identity.rows | default slice -}} {{- if $identityRows -}} {{- with site.GetPage ($identity.page | default "/") -}} {{- $idPage := . -}} {{- $rendered := slice -}} {{- range $identityRows -}} {{- if reflect.IsMap . -}} {{- $k := lower (trim (printf "%v" (.key | default "")) " \t\n\r") -}} {{/* The label is captured HERE, before any inner `with` rebinds the dot: inside a partial `$` is the partial's own context dict, never the range item, so reaching for the label from within the value block would silently render the key instead. */}} {{- $label := partial "agent-readiness/lib/inline.html" (.label | default $k) -}} {{- if $k -}} {{/* Flattened through the shared routine, so an identity row naming a list-valued key reads "a, b" rather than Go's debug form "[a b]" -- and reads identically to the same key rendered as a section bullet below. */}} {{- with partial "agent-readiness/lib/flatten-value.html" (index $idPage.Params $k) -}} {{- $rendered = $rendered | append (printf "- **%s**: %s" $label .) -}} {{- end -}} {{- end -}} {{- else -}} {{/* A bare value inside a real slice. Dropped silently it withholds the whole `## Identity` block of the one-fetch facts document. */}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:identity-row-not-a-table:%v" .) "message" (printf "[agent-readiness] Skipping the [[params.agent.facts.identity.rows]] entry %q: a row must be a table with `label` and `key`, not a bare value." (printf "%v" .))) -}} {{- end -}} {{- end -}} {{- with $rendered -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $cfg.i18n.facts_identity_heading)) | append "" -}} {{- range . -}}{{- $lines = $lines | append . -}}{{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* 4. One H2 per configured section, COMPLETE. Membership comes from the shared filter, so this document lists exactly the pages the twins emit and llms.txt links. Each entry's `section` value arrived here already normalized by config.html. */}} {{- $all := partialCached "agent-readiness/page-list.html" (dict "page" $page "cfg" $cfg) site.Language.Name -}} {{- range $entry := $facts.sections | default slice -}} {{- $section := $entry.section | default "" -}} {{- $name := $entry.name | default "" -}} {{/* Refused rather than rendered, for the reasons llms.html states at the same point: an empty `section` matches every page because the prefix test degenerates to hasPrefix .Path "/", and a nameless entry has no H2, so its bullets would be read as belonging to the section above it. Both surfaces share the machinery, so they share the guard. */}} {{- if not $section -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:facts-section-empty:%s" $name) "message" (printf "[agent-readiness] Skipping the [[params.agent.facts.sections]] entry named %q: its `section` is empty, and an empty section matches every page, so the entry would list the whole site under one heading. Set `section` to a section path such as '/projects' -- note the key is `section`, singular." $name)) -}} {{- else if not $name -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:facts-section-unnamed:%s" $section) "message" (printf "[agent-readiness] Skipping the [[params.agent.facts.sections]] entry for %q: it has no `name`, so it has no H2 of its own and its entries would be read as belonging to the section above it. Give the entry a `name`." $section)) -}} {{- else -}} {{- $items := slice -}} {{- range $all -}} {{- $p := .Path -}} {{- if or (eq $p $section) (hasPrefix $p (printf "%s/" $section)) (eq (printf "/%s" .Section) $section) -}} {{- $items = $items | append . -}} {{- end -}} {{- end -}} {{/* A section matching NOTHING is withheld rather than published as a bare heading, for the reason llms.html states at the same point: an empty section reads as a fact about the site rather than as a configuration error. This document is the one-fetch answer to "what have they built", so an empty H2 here answers it wrongly. */}} {{- if not $items -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:facts-section-empty-result:%s" $section) "message" (printf "[agent-readiness] The [[params.agent.facts.sections]] entry %q matches no page at %q, so its heading is omitted rather than published empty. Check the section path against your content tree, and check that it is admitted by the top-level `sections` allow-list if you set one." $name $section)) -}} {{- else -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $name)) | append "" -}} {{- range $item := $items -}} {{/* One TOP-LEVEL bullet per page: the count of these is the assertion the fixture makes against the filter's page count. Absolute, like every other URL this document emits. */}} {{- $bullet := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" $item.Title "url" $item.Permalink)) -}} {{/* Gated on markdown.enable as well as link_markdown, for the reason llms.html states at the same point: the output format answers "is it wired", not "was anything rendered into it", and the twin is the module's own to emit or withhold. */}} {{- if and $facts.link_markdown $cfg.markdown.enable -}} {{- with $item.OutputFormats.Get "markdown" -}} {{- $bullet = printf "%s (%s)" $bullet (partial "agent-readiness/lib/markdown-link.html" (dict "name" "Markdown" "url" .Permalink)) -}} {{- end -}} {{- end -}} {{- $lines = $lines | append $bullet -}} {{/* Nested bullets: the same per-section field map the twins use, looked up the SAME way they look it up -- off the page's own .Section, exactly as markdown-front-matter.html does. Keying it off the configured section path instead would silently read no vocabulary for a nested entry such as section = 'docs/guides', whose twins key on 'docs'. One page, one vocabulary, one lookup. */}} {{- $map := index $cfg.frontmatter (lower $item.Section) -}} {{- if reflect.IsMap $map -}} {{- range $key := ($map.keys | default slice) -}} {{- $k := lower (trim (printf "%v" $key) " \t\n\r") -}} {{- if $k -}} {{- with partial "agent-readiness/lib/flatten-value.html" (index $item.Params $k) -}} {{- $lines = $lines | append (printf " - %s: %s" (partial "agent-readiness/lib/inline.html" $k) .) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* 5. Contact block, read from a real content page's front-matter array. An entry carrying none of the three configured fields is skipped; nothing here is retyped into config, so the block cannot contradict the contact page. */}} {{- $contact := $facts.contact | default dict -}} {{- with $contact.page -}} {{- with site.GetPage . -}} {{- $channels := index .Params (lower ($contact.key | default "channels")) -}} {{- $rendered := slice -}} {{/* Coerced rather than gated on IsSlice: gating made a mis-typed value behave exactly like an absent contact page. The per-entry map test below keeps its own else arm, so a bare entry inside a real slice is reported rather than vanishing. */}} {{- range partial "agent-readiness/lib/map-list.html" $channels -}} {{- if reflect.IsMap . -}} {{- $label := partial "agent-readiness/lib/inline.html" (index . (lower ($contact.label_field | default "label")) | default "") -}} {{- $value := partial "agent-readiness/lib/inline.html" (index . (lower ($contact.value_field | default "value")) | default "") -}} {{- $url := partial "agent-readiness/lib/inline.html" (index . (lower ($contact.url_field | default "href")) | default "") -}} {{/* A site-relative href authored on the contact page is resolved through the shared routine; anything carrying a scheme (https:, mailto:, tel:) is passed through untouched. about.md is read detached from the site far more often than it is read on it, and a bare /contact/ resolves against whatever origin the reader happens to be on. */}} {{- $url = partial "agent-readiness/lib/absolute-url.html" $url -}} {{- if or $label $value $url -}} {{/* An entry carrying ONLY a url would otherwise render `- : [](https://...)` -- an empty label, an empty link text, and a stray colon. That is the same empty-link-text failure the license line is guarded against in llms.html, and the module ships no design decision about what such a link should be called, so the URL speaks for itself in both slots rather than a fabricated name. */}} {{- $text := $value | default $label | default $url -}} {{- $line := "" -}} {{- if $url -}} {{- $line = printf "- %s: %s" ($label | default $text) (partial "agent-readiness/lib/markdown-link.html" (dict "name" $text "url" $url)) -}} {{- else -}} {{- $line = printf "- %s: %s" ($label | default $text) $text -}} {{- end -}} {{- $rendered = $rendered | append $line -}} {{- end -}} {{- else -}} {{/* A bare value inside a real slice. Dropped silently it removes the channel from the contact block with no signal. */}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:contact-channel-not-a-table:%v" .) "message" (printf "[agent-readiness] Skipping the contact channel %q: a channel must be a table carrying the configured label, value and href fields, not a bare value." (printf "%v" .))) -}} {{- end -}} {{- end -}} {{- with $rendered -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $cfg.i18n.facts_contact_heading)) | append "" -}} {{- range . -}}{{- $lines = $lines | append . -}}{{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* 6. Trailing pointer section. Every pointer is absolute, so the document stays usable when it is read detached from the site. llms.txt IS a home output format and resolves through it. `sitemap` is NOT -- it is a page KIND -- so the OutputFormats lookup below never matches and the absURL fallback always wins. The lookup is kept because it costs nothing and would start working if Hugo ever exposed the sitemap that way; the fallback is what actually runs, and it carries the baseURL path but no language prefix. */}} {{- if $facts.sitemap_section -}} {{- $pointers := slice -}} {{/* llms.enable is consulted as well as the format being wired: the output format answers "is it wired", not "did llms.html render anything into it". With the switch off the document is never published, so this pointer would be a dead link. */}} {{- if $cfg.llms.enable -}} {{- with site.Home.OutputFormats.Get "llmstxt" -}} {{- $pointers = $pointers | append (printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" "llms.txt" "url" .Permalink))) -}} {{- end -}} {{- end -}} {{- $sitemapURL := "sitemap.xml" | absURL -}} {{- with site.Home.OutputFormats.Get "sitemap" -}} {{- $sitemapURL = .Permalink -}} {{- end -}} {{- $pointers = $pointers | append (printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" "sitemap.xml" "url" $sitemapURL))) -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $cfg.i18n.sitemap_heading)) | append "" -}} {{- range $pointers -}}{{- $lines = $lines | append . -}}{{- end -}} {{- end -}} {{/* safeHTML because this partial lives in the .html template namespace while about.md is a standalone plain-text document: without it every ampersand and angle bracket in a page title would be HTML-escaped into an entity in a file that is not HTML. */}} {{- printf "%s\n" (delimit $lines "\n") | safeHTML -}} {{- end -}}
