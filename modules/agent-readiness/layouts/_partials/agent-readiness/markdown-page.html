{{/* agent-readiness/markdown-page.html -- renderer (RENDERER tier). Purpose: render one Markdown twin -- the front-matter block, the page body, and an optional trailing pointer section. MEMBERSHIP: the twin emits NOTHING AT ALL for a page the shared filter excludes, so the twin surface can never disagree with robots.txt, llms.txt and about.md about which pages of the site exist. A template that renders no bytes makes Hugo publish no file for that format, so an excluded page ends up with no index.md beside its index.html rather than an empty one -- which is what 02-twins.spec.js asserts. BODY SOURCE: .RenderShortcodes, which is the only one of Hugo's four content accessors that yields a document that is simultaneously valid Markdown prose and complete. .RawContent leaves every shortcode call as the literal, unexpanded call text; .Content renders the surrounding Markdown to HTML too, producing an HTML document with a .md extension; .Plain strips every tag and destroys headings, lists, links and code fences. Reconstructing Markdown from .Content is possible -- transform.HTMLToMarkdown exists as of v0.151.0 -- but it is still experimental and would put the twin through a lossy Markdown-to-HTML-to-Markdown round trip, so the accessor that never leaves Markdown wins on both counts. The documented consequence: a twin of a shortcode-heavy page contains raw HTML blocks inline. That is valid CommonMark, and for a page whose entire value is a rendered widget the widget markup IS the content. Relative links inside the body need no rewriting: index.md sits in the same published directory as index.html, so every relative reference resolves identically from either. Expected context (dict): - .page (Page) - The page whose twin is being rendered. - .cfg (dict) - The resolved config from agent-readiness/config.html. Return value: none. This partial renders. */}} {{- $page := .page -}} {{- $cfg := .cfg -}} {{- $md := $cfg.markdown -}} {{- if and $cfg.enable $md.enable -}} {{/* MEMBERSHIP, by kind. A regular page must appear in the shared enumeration, which is what keeps the twin set identical to the set llms.txt and about.md list. The home page and a section list page are never in that enumeration -- site.RegularPages excludes them, because they are the containers of an enumeration rather than members of one -- so they are tested against the same per-page rules directly. The section allow-list still applies to a section page (a site scoping its agent surface to /blog does not want a /projects/ section twin), but never to the home page, which is the site root rather than a section member. */}} {{- $included := false -}} {{- if eq $page.Kind "page" -}} {{- range partialCached "agent-readiness/page-list.html" (dict "page" $page "cfg" $cfg) site.Language.Name -}} {{- if eq .Path $page.Path -}}{{- $included = true -}}{{- end -}} {{- end -}} {{- else -}} {{- $searchPagePath := "" -}} {{- if $cfg.exclude_search_page -}} {{- with site.GetPage $cfg.search_page_path -}} {{- $searchPagePath = .Path -}} {{- end -}} {{- end -}} {{- $included = not (partial "agent-readiness/lib/page-excluded.html" (dict "page" $page "cfg" $cfg "search_page_path" $searchPagePath)) -}} {{- if and $included $cfg.sections (eq $page.Kind "section") -}} {{- $inScope := false -}} {{- $p := $page.Path -}} {{- range $cfg.sections -}} {{- if or (eq $p .) (hasPrefix $p (printf "%s/" .)) -}}{{- $inScope = true -}}{{- end -}} {{- end -}} {{- $included = $inScope -}} {{- end -}} {{- end -}} {{- if $included -}} {{/* safeHTML because this partial lives in the .html template namespace while the twin it feeds is a standalone plain-text document: without it, the builder's quotes come out as " and every front-matter block is unparseable. .RenderShortcodes below needs no such marking because it already returns template.HTML. */}} {{- partial "agent-readiness/markdown-front-matter.html" (dict "page" $page "cfg" $cfg) | safeHTML -}} {{- $page.RenderShortcodes -}} {{/* Trailing pointer section. The target is resolved through the home page's output formats rather than a hardcoded path, so a subpath baseURL or a language prefix is honored, and it is emitted as an ABSOLUTE URL because a twin is routinely read detached from the site it came from, where a relative path has no base to resolve against. The configured target is case-folded and trimmed before it is matched. Every other enumerated value in this module is normalized the same way, and here an unnormalized miss is invisible: "LLMS" would match no branch, leave the target empty and emit nothing at all, with no warning and exit 0. An unrecognized value now says so once rather than silently dropping the section. */}} {{- $wanted := lower (trim (printf "%v" ($md.sitemap_section_target | default "llms")) " \t\n\r") -}} {{- if and $md.sitemap_section (ne $wanted "none") -}} {{- $target := "" -}} {{- $label := "" -}} {{- if eq $wanted "llms" -}} {{/* Gated on llms.enable as well as on the format being wired, for the same reason the twin links are gated on markdown.enable: the output format answers "is it wired", not "did llms.html render anything into it". With the switch off, llms.html emits zero bytes and Hugo publishes no /llms.txt, so pointing at it would put a dead link in the tail of every twin. Switched off deliberately, so no warning -- unlike the wired case below, where the consumer asked for the pointer and the format is missing, which they cannot see without being told. */}} {{- if $cfg.llms.enable -}} {{- with site.Home.OutputFormats.Get "llmstxt" -}} {{- $target = .Permalink -}} {{- $label = "llms.txt" -}} {{- else -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" "agent-readiness:warn:sitemap-section-no-llmstxt" "message" "[agent-readiness] The Markdown twins are configured with sitemap_section_target = \"llms\", but the llmstxt output format is not wired to the home page, so the trailing pointer section is omitted. Add 'llmstxt' to your existing [outputs] home list -- the config list replaces the ENTIRE default home list, so keep every format you already wire there -- or set sitemap_section_target to \"sitemap\" or \"none\".") -}} {{- end -}} {{- end -}} {{- else if eq $wanted "sitemap" -}} {{- with site.Home.OutputFormats.Get "sitemap" -}} {{- $target = .Permalink -}} {{- else -}} {{- $target = "sitemap.xml" | absURL -}} {{- end -}} {{- $label = "sitemap.xml" -}} {{- else -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:unknown-sitemap-target:%s" $wanted) "message" (printf "[agent-readiness] Ignoring the unrecognized markdown.sitemap_section_target %q and omitting the twins' trailing pointer section. Use \"llms\", \"sitemap\", or \"none\"." $wanted)) -}} {{- end -}} {{/* Assembled with an explicit terminating newline rather than written inline: the closing trim marker of an inline block eats the final newline, and a text document ends with one -- the same standard robots.txt, llms.txt and about.md are held to. safeHTML because this partial is in the .html namespace while the twin is plain text, so an ampersand in the URL would otherwise become an entity. */}} {{- with $target -}} {{- printf "\n\n## %s\n\n- [%s](%s)\n" $cfg.i18n.sitemap_heading $label . | safeHTML -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}}
