{{/* agent-readiness/page-list.html -- INTERNAL (resolver tier). Purpose: THE shared page-selection filter. Every surface that ENUMERATES pages -- llms.txt, about.md, and the twin membership test for regular pages -- resolves membership through this one partial, which is the whole reason the module ships as one adoption decision rather than five: without it, a section excluded from one surface and not another would make the site advertise in llms.txt a URL its own twins never emit. Filters, applied in this order: 1. Master switch -- cfg.enable false returns an empty slice. 2. Section allow-list, matched at SEGMENT boundaries so `docs` never matches /docs-internal/. An empty allow-list admits every regular page. 3. The per-page rules, delegated to agent-readiness/lib/page-excluded.html so the twin renderer applies exactly the same ones to the home and section pages, which are not regular pages and so never appear here. 4. Duplicate permalinks -- the first page wins and each collision warns once. A newScratch sentinel is used rather than a dict accumulator because Go's merge folds map keys case-insensitively, so a case-variant permalink would swallow a later true duplicate's sentinel along with its warning. SCOPE: this ranges site.RegularPages, so it never contains the home page or a section list page. That is deliberate -- those pages are not members of an enumeration, they are the containers of one -- and it is why markdown-page.html tests them through lib/page-excluded.html directly instead of asking for membership here. Expected context (dict): - .page (Page) - The calling page, used only for diagnostics. - .cfg (dict) - The resolved config from agent-readiness/config.html. Return value: the ordered slice of Pages every enumerating surface agrees on (possibly empty). ONE terminal return. */}} {{- $cfg := .cfg -}} {{- $pages := slice -}} {{- if $cfg.enable -}} {{/* The dedicated search page is resolved ONCE, by path, rather than compared as a string per page: site.GetPage honors the language tree and any url front matter, which a raw path comparison would not. */}} {{- $searchPagePath := "" -}} {{- if $cfg.exclude_search_page -}} {{- with site.GetPage $cfg.search_page_path -}} {{- $searchPagePath = .Path -}} {{- end -}} {{- end -}} {{- $seen := newScratch -}} {{- range site.RegularPages -}} {{- $keep := true -}} {{/* 2. Section scope: equality or normalized-entry-plus-slash prefix, so `docs` never matches /docs-internal/... and docs/guides never matches /docs/guides-old/.... The .Section comparison admits a section's own pages when the allow-list names the section by name; the .Path comparisons admit nested paths. */}} {{- if $cfg.sections -}} {{- $keep = false -}} {{- $p := .Path -}} {{- $section := .Section -}} {{- range $cfg.sections -}} {{- if or (eq (printf "/%s" $section) .) (eq $p .) (hasPrefix $p (printf "%s/" .)) -}} {{- $keep = true -}} {{- end -}} {{- end -}} {{- end -}} {{/* 3. The shared per-page rules. */}} {{- if $keep -}} {{- if partial "agent-readiness/lib/page-excluded.html" (dict "page" . "cfg" $cfg "search_page_path" $searchPagePath) -}} {{- $keep = false -}} {{- end -}} {{- end -}} {{/* 4. Duplicate permalinks: two pages published to one URL would be listed twice in llms.txt and about.md while only one twin exists on disk, so the first wins and the collision is reported. */}} {{- if $keep -}} {{- $key := .RelPermalink -}} {{- if $seen.Get $key -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:duplicate-permalink:%s" $key) "message" (printf "[agent-readiness] Skipping the duplicate agent-surface entry for %s: another page already publishes this permalink, so listing it twice would advertise a URL whose Markdown twin belongs to a different page." $key)) -}} {{- else -}} {{- $seen.Set $key true -}} {{- $pages = $pages | append . -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $pages -}}
