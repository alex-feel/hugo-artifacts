An entry is present ONLY when its document publishes; the slice may be empty. ONE terminal return. PUBLISHED, not merely wired. Each surface's output format answers "is the format wired in the consumer's [outputs]", while its renderer decides whether any bytes exist -- and a template that renders zero bytes makes Hugo publish NO file. The gate set lives in lib/llms-index-url.html -- shared with the derived `## Start here` entry in llms.html, so the two callers cannot drift apart -- and that partial also carries the warn-once for the enabled-but-unwired case. - facts: cfg.enable AND facts.enable AND the agentfacts format wired on the page's own language home; the same enabled-means-bytes reasoning, and likewise per-language. - skills: ALL FOUR gates of home.agentskills.json, evaluated against the DEFAULT site. The gates live in lib/skills-index-url.html -- shared with the llms.txt `## Optional` auto-entry in llms.html, so the two callers cannot drift apart -- and that partial returns the index URL only when the file actually publishes, resolving the default-site config and the skills slice once per build. Expected context: the current Page, or a dict whose "page" key is the current Page plus an optional "args" map of call-site config overrides (the top tier of the module's four-tier cascade).
