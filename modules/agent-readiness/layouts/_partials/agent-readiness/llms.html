{{/* agent-readiness/llms.html -- renderer (RENDERER tier). Purpose: render /llms.txt, the llmstxt.org link index. What this file is and is not: it is a LINK INDEX and carries no facts of its own. The facts document (about.md) is the surface that answers "who is this and what have they done"; this one answers "what pages exist and where are their machine-readable forms". llmstxt.org is a community convention with no registration authority and no confirmed major-crawler consumer -- see the README, which says so plainly rather than presenting the file as an SEO or citation lever. The value it does carry is that it is build-generated from the SAME page collection as every other surface, through agent-readiness/page-list.html, so it cannot drift stale and cannot list a URL the twins never emit. Structure, per the convention: 1. Exactly one `# ` H1. 2. A `> ` one-line blockquote summary (omitted rather than emitted hollow). 3. An optional `> ` license line, placed after the summary and before the first `## `. 4. Optional free prose. 5. A `## ` H2 carrying ONE derived entry, the home page's own Markdown twin, when that twin publishes. 6. One `## ` H2 per configured section, each listing `- [name](url): note`. 7. A final `## Optional` H2: the consumer's declared entries, plus ONE derived entry for the module's own Agent Skills index when that surface actually publishes. `Optional` is a protocol token fixed by the convention and is deliberately NOT translated. The heading in slot 5 is not a protocol token -- the convention reserves no name for a site's entry point and leaves every other H2 name free -- so that one IS translated, through $cfg.i18n. The document is assembled as a slice of lines and emitted once, rather than written inline with whitespace-trimming markers: this file's output is whitespace-significant plain text, and line assembly is the only way to keep blank-line placement exact and reviewable. Because the document is line-oriented, every interpolated value goes through lib/inline.html -- or lib/markdown-link.html when it lands inside a link -- before it joins its line: a value-borne line break is a structure change here, not text, and an unescaped bracket in a link text or parenthesis in a destination ends the link's own syntax early. The one exception is the free-prose `notes` slot, which is block content by design. Expected context (dict): - .page (Page) - The home page. - .cfg (dict) - The resolved config from agent-readiness/config.html. Return value: none. This partial renders. */}} {{- $page := .page -}} {{- $cfg := .cfg -}} {{- $llms := $cfg.llms -}} {{- if and $cfg.enable $llms.enable -}} {{- $lines := slice -}} {{/* The consumer's `## Optional` entries are COLLECTED here but EMITTED last. Both of this file's derived entries -- the home twin in slot 5 and the Agent Skills index in slot 7 -- suppress themselves when the consumer already declared the same URL, and the home twin's slot comes before the sections, so the dedup list has to exist before the document body is assembled. Collecting once, up front, keeps ONE list for both and keeps the two derived entries from ever disagreeing about what counts as already-declared. Absolutized through the shared routine, which handles the leading-slash form correctly -- passing it to absURL directly would discard the baseURL's path on a subpath deployment. */}} {{- $optional := slice -}} {{- $optionalUrls := slice -}} {{- range $llms.optional | default slice -}} {{- if reflect.IsMap . -}} {{- $u := partial "agent-readiness/lib/absolute-url.html" (.url | default "") -}} {{- if $u -}} {{- $item := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" (.name | default $u) "url" $u)) -}} {{- with .note -}}{{- $item = printf "%s: %s" $item (partial "agent-readiness/lib/inline.html" .) -}}{{- end -}} {{- $optional = $optional | append $item -}} {{- $optionalUrls = $optionalUrls | append $u -}} {{- end -}} {{- else -}} {{/* A bare value inside a real slice. Dropped silently it removes the whole `## Optional` heading, which reads as a deliberate omission. */}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:optional-not-a-table:%v" .) "message" (printf "[agent-readiness] Skipping the [[params.agent.llms.optional]] entry %q: an entry must be a table with `name` and `url`, not a bare value." (printf "%v" .))) -}} {{- end -}} {{- end -}} {{/* 1. Exactly one H1. */}} {{- $lines = $lines | append (printf "# %s" (partial "agent-readiness/lib/inline.html" ($llms.title | default site.Title))) -}} {{/* 2. The one-line summary. */}} {{- with $llms.summary -}} {{- $lines = $lines | append "" | append (printf "> %s" (partial "agent-readiness/lib/inline.html" .)) -}} {{- end -}} {{/* 3. The license line. Composed as [name](url) and guarded on BOTH fields: guarding on url alone would publish a Markdown link with an empty label the moment a consumer set url without name. */}} {{- if and $llms.license $cfg.license.url -}} {{- if $cfg.license.name -}} {{- $lines = $lines | append "" | append (printf "> Content licensed under %s." (partial "agent-readiness/lib/markdown-link.html" (dict "name" $cfg.license.name "url" $cfg.license.url))) -}} {{- else -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" "agent-readiness:warn:license-name-missing" "message" "[agent-readiness] Skipping the llms.txt license line: [params.agent.license] url is set but name is empty, and the line is composed as [name](url), so emitting it would publish a Markdown link with an empty label. Set both name and url, or leave the whole table empty.") -}} {{- end -}} {{- end -}} {{/* 4. Optional free prose. Appended verbatim, embedded line breaks included: this is the document's one block-content slot, so a multi-line value here is the consumer writing prose paragraphs, not a field value leaking structure. */}} {{- with $llms.notes -}} {{- $lines = $lines | append "" | append . -}} {{- end -}} {{/* 5. The home page's own Markdown twin. WHY IT IS DERIVED RATHER THAN CONFIGURED. This file lists pages only through [[params.agent.llms.sections]], and section membership is a content-path prefix test. The home page's Path is "/", which belongs to no section and which no section value can reach: '/' normalizes to the empty string, which slot 6's empty-section guard refuses, and any real section value fails the prefix test against "/". So on every site that enables twins, the one twin an agent is most likely to fetch first -- the front door, carrying the identity block and whatever the home page says about the site -- was the one twin this index could never name, and no consumer could fix it except by hand-writing an [[llms.optional]] entry whose URL the module already knows how to compute, which drifts the day that URL or its publish state changes. The gates are the module's own public answer, not a second copy of them: agent-readiness/twin-url.html applies the master switch, the twin surface switch, the per-page opt-out in home front matter, and the `markdown` format being wired for the home kind, returning "" if any of them withholds the file. So this section publishes a link only when the file it points at exists, and emits nothing at all -- no heading, no warning -- otherwise. link_markdown gates it too: a site that told llms.txt not to link twins gets no twin link here either, which keeps this slot consistent with the section bullets below rather than making the home page the one exception. PLACEMENT, and why not `## Optional`. The Agent Skills entry in slot 7 is derived the same way, so `## Optional` is where the machinery already lives -- but the convention defines that heading as links that "can be skipped if a shorter context is needed... secondary information which can often be skipped", and a site's front door is the last thing an agent should drop. The convention reserves no name for an entry point and constrains no other H2 name, and of the generated llms.txt files surveyed for this decision the only one that links its own overview at all puts it first, ahead of the ordinary sections. So this gets its own translated H2 in first position. Preamble prose was rejected for the same reason the rest of this document is a link list: an agent parses `- [name](url)`, not a sentence. A consumer who already listed this URL in [[llms.optional]] keeps their own name and note. The derived entry is suppressed rather than doubled, comparing absolutized URLs exactly as the skills entry does. The link text is the home page's own Title and the note its own Description, so the entry restates nothing a consumer would have to maintain twice. */}} {{- if $llms.link_markdown -}} {{- with partial "agent-readiness/twin-url.html" $page -}} {{- if not (in $optionalUrls .) -}} {{- $homeItem := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" ($page.Title | default site.Title) "url" .)) -}} {{- with $page.Description -}} {{- $homeItem = printf "%s: %s" $homeItem (partial "agent-readiness/lib/inline.html" .) -}} {{- end -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $cfg.i18n.llms_start_heading)) | append "" | append $homeItem -}} {{- end -}} {{- end -}} {{- end -}} {{/* 6. One H2 per configured section. Membership comes from the shared filter, so llms.txt can never list a page the twins and robots.txt disagree about. Each entry's `section` value arrived here already normalized by config.html, so a bare name and a slashed form resolve identically -- an unnormalized mismatch would render an empty H2 with no warning, no error and exit 0. */}} {{- $all := partialCached "agent-readiness/page-list.html" (dict "page" $page "cfg" $cfg) site.Language.Name -}} {{- range $entry := $llms.sections | default slice -}} {{- $section := $entry.section | default "" -}} {{- $name := $entry.name | default "" -}} {{/* Two entry shapes are refused rather than rendered, because both fail INVISIBLY -- exit 0, plausible-looking output, wrong content. An empty `section` matches EVERY page: the prefix test degenerates to hasPrefix .Path "/", which every page in the site satisfies. A single `sections =` for `section =` typo would therefore publish the entire site under one heading and look deliberate. An entry with no `name` has no H2 to open, and because the document is assembled as one flat slice of lines its bullets would be appended directly beneath the PREVIOUS entry's last bullet, where every Markdown parser reads them as that section's links. */}} {{- if not $section -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:llms-section-empty:%s" $name) "message" (printf "[agent-readiness] Skipping the [[params.agent.llms.sections]] entry named %q: its `section` is empty, and an empty section matches every page, so the entry would list the whole site under one heading. Set `section` to a section path such as '/blog' -- note the key is `section`, singular." $name)) -}} {{- else if not $name -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:llms-section-unnamed:%s" $section) "message" (printf "[agent-readiness] Skipping the [[params.agent.llms.sections]] entry for %q: it has no `name`, so it has no H2 of its own and its links would be read as belonging to the section above it. Give the entry a `name`." $section)) -}} {{- else -}} {{- $items := slice -}} {{- range $all -}} {{- $p := .Path -}} {{- if or (eq $p $section) (hasPrefix $p (printf "%s/" $section)) (eq (printf "/%s" .Section) $section) -}} {{- $items = $items | append . -}} {{- end -}} {{- end -}} {{/* `int` raises a template error on a non-numeric value, which would stop the build over a config typo -- against the contract that this module never does that. A non-numeric limit is reported and read as 0, which means "complete". */}} {{- $rawLimit := printf "%v" ($entry.limit | default 0) -}} {{- $limit := 0 -}} {{- if findRE `^[0-9]+$` $rawLimit -}} {{- $limit = int $rawLimit -}} {{- else -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:llms-bad-limit:%s" $rawLimit) "message" (printf "[agent-readiness] The [[params.agent.llms.sections]] entry %q has a non-numeric `limit` (%q); listing the section complete. Use a non-negative whole number, where 0 means complete." $name $rawLimit)) -}} {{- end -}} {{- if and (gt $limit 0) (gt (len $items) $limit) -}} {{- $items = first $limit $items -}} {{- end -}} {{/* A section that matches NOTHING is the likeliest real instance of the empty-H2 failure the guards above name -- `section = 'blogs'` normalizes cleanly, passes both guards, matches no page, and publishes a heading with no items under it. The heading is withheld and the mismatch named, because an empty section in a link index reads as "this site has no blog posts" rather than as "this configuration is wrong". */}} {{- if not $items -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:llms-section-empty-result:%s" $section) "message" (printf "[agent-readiness] The [[params.agent.llms.sections]] entry %q matches no page at %q, so its heading is omitted rather than published empty. Check the section path against your content tree, and check that it is admitted by the top-level `sections` allow-list if you set one." $name $section)) -}} {{- else -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $name)) | append "" -}} {{/* Absolute URLs: llms.txt is routinely ingested detached from the URL it was fetched from, and a relative path has no origin to resolve against there. The twin URL is substituted only when the twin will actually EXIST. `.OutputFormats.Get "markdown"` answers "is the format wired for this page kind", which is a question about the consumer's [outputs] lists, NOT about whether this module rendered anything into it -- markdown-page.html is the sole producer and it emits nothing when the switch is off, which makes Hugo publish no file. Consulting the format alone would therefore list a URL that 404s for every page on a site that turned the twins off but left `markdown` wired, which is exactly the configuration the module tells consumers to use. */}} {{- range $items -}} {{- $url := .Permalink -}} {{- if and $llms.link_markdown $cfg.markdown.enable -}} {{- with .OutputFormats.Get "markdown" -}}{{- $url = .Permalink -}}{{- end -}} {{- end -}} {{- $item := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" .Title "url" $url)) -}} {{- with .Description -}}{{- $item = printf "%s: %s" $item (partial "agent-readiness/lib/inline.html" .) -}}{{- end -}} {{- $lines = $lines | append $item -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* 7. The Optional section: links an agent may drop when shortening context. It holds the consumer's declared entries, collected at the top of this file, plus the module's own derived entry below, and the H2 is emitted only when at least one entry of either kind survived, because an empty H2 claims a section that is not there. The module's own Agent Skills index belongs HERE rather than in slot 5, and the contrast is the reason slot 5 exists: the skills index is genuinely secondary -- a machine-readable listing an agent can drop without losing the site -- while the home twin is the front door. The index file is otherwise reachable only by well-known-path convention, so llms.txt is where an agent actually discovers it; the entry is DERIVED from module state, and no consumer action is needed. lib/skills-index-url.html carries the four publish gates shared with surfaces.html, so a zero-skills or unwired build appends nothing here -- no entry, no warning. A consumer who already lists the index in [[params.agent.llms.optional]] keeps their own wording: the URLs are compared after absolutization, and a match suppresses the derived entry rather than doubling it. */}} {{- with partial "agent-readiness/lib/skills-index-url.html" dict -}} {{- if not (in $optionalUrls .) -}} {{- $item := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" $cfg.i18n.skills_entry_name "url" .)) -}} {{- $item = printf "%s: %s" $item (partial "agent-readiness/lib/inline.html" $cfg.i18n.skills_entry_note) -}} {{- $optional = $optional | append $item -}} {{- end -}} {{- end -}} {{- with $optional -}} {{- $lines = $lines | append "" | append "## Optional" | append "" -}} {{- range . -}}{{- $lines = $lines | append . -}}{{- end -}} {{- end -}} {{/* safeHTML because this partial lives in the .html template namespace while llms.txt is a standalone plain-text document: without it every ampersand and angle bracket in a page title would be HTML-escaped into an entity in a file that is not HTML. */}} {{- printf "%s\n" (delimit $lines "\n") | safeHTML -}} {{- end -}}
