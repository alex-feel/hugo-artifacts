{{/* agent-readiness/llms.html -- renderer (RENDERER tier). Purpose: render the llms.txt family -- BOTH documents, from ONE page walk. /llms.txt the COMPACT index (this partial's default mode). Each configured section carries a SELECTION of its pages, by the principle that section's own configuration names. /llms-index.txt the COMPLETE index (`complete` true). Every page of every configured section, never capped, never filtered by the selection principle. ONE renderer rather than two, because the two documents share everything except the section listings: the H1, the summary, the license and build-time lines, the free prose, the `## Start here` entry, the `## Optional` collection, the link shape, the twin substitution and the escaping. A second renderer would duplicate all of it, and duplication is exactly the drift objection the split has to answer. What differs is one boolean, applied in three places: the complete document's section listing skips selection, no section of it can open with a narrowed-selection notice, and the compact document names the complete one while the complete one does not name itself. What these files are and are not: they are LINK INDEXES and carry no facts of their own. The facts document (about.md) is the surface that answers "who is this and what have they done"; these answer "what pages exist and where are their machine-readable forms". Neither is `llms-full.txt`, which expands the linked pages' CONTENT -- the module still ships no such file, and the twins already publish those bodies at stable URLs. That name belongs to the documentation PLATFORMS that publish it, not to llmstxt.org, which has never named it in either version of the proposal. llmstxt.org is a community convention with no registration authority and no confirmed major-crawler consumer -- see the README, which says so plainly rather than presenting the file as an SEO or citation lever. The value they do carry is that they are build-generated from the SAME page collection as every other surface, through agent-readiness/page-list.html and the shared membership test in lib/section-pages.html, so they cannot drift stale, cannot list a URL the twins never emit, and cannot disagree with each other about what a section holds. Structure, per the convention, identical in both documents: 1. Exactly one `# ` H1. 2. A `> ` one-line blockquote summary (omitted rather than emitted hollow). 3. An optional `> ` license line, placed after the summary and before the first `## `. 4. An optional `> Build time: ` line, immediately after the license line. 5. Optional free prose. 6. A `## ` H2 collecting the derived route entries -- the home page's own Markdown twin, then (compact document only) the complete index -- and emitted only when at least one of them survived. 7. One `## ` H2 per configured section, each listing `- [name](url): note` -- opened, in the compact document only, by one notice item when that section's selection dropped pages the shared filter admitted. 8. A final `## Optional` H2: the consumer's declared entries, plus ONE derived entry for the module's own Agent Skills index when that surface actually publishes. The convention allows slots 3-5: after the H1 and the blockquote summary come "zero or more markdown sections (e.g. paragraphs, lists, etc) of any type except headings" before the H2 file lists. That is the only structural slot this document has, which is why the license and build-time lines share it rather than inventing a comment syntax the convention does not define -- and a leading `#` would be an H1, breaking the exactly-one-H1 rule above. `Optional` is a protocol token fixed by the convention and is deliberately NOT translated. The heading in slot 6 is not a protocol token -- the convention reserves no name for a site's entry point and leaves every other H2 name free -- so that one IS translated, through $cfg.i18n. The document is assembled as a slice of lines and emitted once, rather than written inline with whitespace-trimming markers: this file's output is whitespace-significant plain text, and line assembly is the only way to keep blank-line placement exact and reviewable. Because the document is line-oriented, every interpolated value goes through lib/inline.html -- or lib/markdown-link.html when it lands inside a link -- before it joins its line: a value-borne line break is a structure change here, not text, and an unescaped bracket in a link text or parenthesis in a destination ends the link's own syntax early. The one exception is the free-prose `notes` slot, which is block content by design. Expected context (dict): - .page (Page) - The home page. - .cfg (dict) - The resolved config from agent-readiness/config.html. - .complete (bool) - False (default) renders the compact /llms.txt; true renders the complete /llms-index.txt. Return value: none. This partial renders. */}} {{- $page := .page -}} {{- $cfg := .cfg -}} {{- $complete := .complete | default false -}} {{- $llms := $cfg.llms -}} {{- if and $cfg.enable $llms.enable -}} {{- $lines := slice -}} {{/* The consumer's `## Optional` entries are COLLECTED here but EMITTED last. Both of this file's derived entries -- the route entries in slot 6 and the Agent Skills index in slot 8 -- suppress themselves when the consumer already declared the same URL, and slot 6 comes before the sections, so the dedup list has to exist before the document body is assembled. Collecting once, up front, keeps ONE list for both and keeps the derived entries from ever disagreeing about what counts as already-declared. Absolutized through the shared routine, which handles the leading-slash form correctly -- passing it to absURL directly would discard the baseURL's path on a subpath deployment. */}} {{- $optional := slice -}} {{- $optionalUrls := slice -}} {{- range $llms.optional | default slice -}} {{- if reflect.IsMap . -}} {{- $u := partial "agent-readiness/lib/absolute-url.html" (.url | default "") -}} {{- if $u -}} {{- $item := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" (.name | default $u) "url" $u)) -}} {{- with .note -}}{{- $item = printf "%s: %s" $item (partial "agent-readiness/lib/inline.html" .) -}}{{- end -}} {{- $optional = $optional | append $item -}} {{- $optionalUrls = $optionalUrls | append $u -}} {{- end -}} {{- else -}} {{/* A bare value inside a real slice. Dropped silently it removes the whole `## Optional` heading, which reads as a deliberate omission. */}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:optional-not-a-table:%v" .) "message" (printf "[agent-readiness] Skipping the [[params.agent.llms.optional]] entry %q: an entry must be a table with `name` and `url`, not a bare value." (printf "%v" .))) -}} {{- end -}} {{- end -}} {{/* 1. Exactly one H1. */}} {{- $lines = $lines | append (printf "# %s" (partial "agent-readiness/lib/inline.html" ($llms.title | default site.Title))) -}} {{/* 2. Composed as [name](url) and guarded on BOTH fields: guarding on url alone would publish a Markdown link with an empty label the moment a consumer set url without name. */}} {{- if and $llms.license $cfg.license.url -}} {{- if $cfg.license.name -}} {{- $lines = $lines | append "" | append (printf "> Content licensed under %s." Set both name and url, or leave the whole table empty.") -}} {{- end -}} {{- end -}} {{/* 4. The build-time line: when THIS BUILD ran, identical in every document the build publishes and identical to what the public agent-readiness/build-time.html partial hands a consuming site for its own surfaces. WHY THESE DOCUMENTS CARRY IT. llms.txt is the first document an agent reads and the complete index is the one most likely to be cached, and both are routinely ingested detached from their origin, where no HTTP date survives -- exactly where a staleness detector is worth a line. It is deliberately untranslated, like the license line above: the value's purpose is byte comparison across surfaces, and a translated label would make the comparison language-dependent. THE LABEL-COLON FORM, not prose and no trailing period. A reader extracting the value with a naive trailing capture would otherwise swallow the period into the timestamp; the license line's own period is harmless only because it follows a `)`. Placed strictly AFTER the license line so the preamble's order is deterministic whatever the license switches say. */}} {{- if $llms.build_time -}} {{- $lines = $lines | append "" | append (printf "> Build time: %s" (partial "agent-readiness/lib/inline.html" (partial "agent-readiness/build-time.html" $page))) -}} {{- end -}} {{/* 5. Optional free prose. Appended verbatim, embedded line breaks included: this is the document's one block-content slot, so a multi-line value here is the consumer writing prose paragraphs, not a field value leaking structure. */}} {{- with $llms.notes -}} {{- $lines = $lines | append "" | append . -}} {{- end -}} {{/* 6. The routes: the entries an agent must not drop, COLLECTED first and emitted under one translated H2 only if at least one survived. The collect-then-emit shape is what `## Optional` already uses, and it is required rather than tidy: either entry can be withheld on its own, and a heading emitted for the first would strand the second. 6a. THE HOME PAGE'S OWN MARKDOWN TWIN, derived rather than configured. This file lists pages only through [[params.agent.llms.sections]], and section membership is a content-path prefix test. The home page's Path is "/", which belongs to no section and which no section value can reach: '/' normalizes to the empty string, which slot 7's empty-section guard refuses, and any real section value fails the prefix test against "/". So on every site that enables twins, the one twin an agent is most likely to fetch first -- the front door, carrying the identity block and whatever the home page says about the site -- was the one twin this index could never name, and no consumer could fix it except by hand-writing an [[llms.optional]] entry whose URL the module already knows how to compute, which drifts the day that URL or its publish state changes. The gates are the module's own public answer, not a second copy of them: agent-readiness/twin-url.html applies the master switch, the twin surface switch, the per-page opt-out in home front matter, and the `markdown` format being wired for the home kind, returning "" if any of them withholds the file. So this entry publishes a link only when the file it points at exists, and emits nothing at all -- no entry, no warning -- otherwise. link_markdown gates it too: a site that told llms.txt not to link twins gets no twin link here either, which keeps this slot consistent with the section bullets below rather than making the home page the one exception. 6b. It is gated through lib/llms-index-url.html, which answers "does that file actually publish" -- the surface switch plus the llmsindex format being wired for the home kind -- and warns once when the surface is enabled and the wiring is missing, because `[outputs]` is consumer-authored and does not merge from module configuration. PLACEMENT, and why not `## Optional`. The Agent Skills entry in slot 8 is derived the same way, so `## Optional` is where the machinery already lives -- but the convention defines that heading as links that "can be skipped if a shorter context is needed... secondary information which can often be skipped", and neither a site's front door nor the only route to the pages a cap dropped is something an agent should drop. The convention reserves no name for an entry point and constrains no other H2 name, and of the generated llms.txt files surveyed for this decision the only one that links its own overview at all puts it first, ahead of the ordinary sections. So these get their own translated H2 in first position. Preamble prose was rejected for the same reason the rest of this document is a link list: an agent parses `- [name](url)`, not a sentence. A consumer who already listed either URL in [[llms.optional]] keeps their own name and note. The derived entry is suppressed rather than doubled, comparing absolutized URLs exactly as the skills entry does. The home entry's link text is the home page's own Title and its note that page's own Description, so it restates nothing a consumer would have to maintain twice. */}} {{- $routes := slice -}} {{- if $llms.link_markdown -}} {{- with partial "agent-readiness/twin-url.html" $page -}} {{- if not (in $optionalUrls .) -}} {{- $homeItem := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" ($page.Title | default site.Title) "url" .)) -}} {{- with $page.Description -}} {{- $homeItem = printf "%s: %s" $homeItem (partial "agent-readiness/lib/inline.html" .) -}} {{- end -}} {{- $routes = $routes | append $homeItem -}} {{- end -}} {{- end -}} {{- end -}} {{/* Resolved ONCE, here, because slot 7 reads it too: a section the selection narrowed carries a notice naming the same file. Calling the gate per section would repeat the wiring lookup for every heading and leave two call sites free to disagree about what "publishes" means. */}} {{- $indexUrl := "" -}} {{- if not $complete -}} {{- $indexUrl = partial "agent-readiness/lib/llms-index-url.html" (dict "page" $page "cfg" $cfg) -}} {{- with $indexUrl -}} {{- if not (in $optionalUrls .) -}} {{- $indexItem := printf "- %s" (partial "agent-readiness/lib/markdown-link.html" (dict "name" $cfg.i18n.llms_index_entry_name "url" .)) -}} {{- $indexItem = printf "%s: %s" $indexItem (partial "agent-readiness/lib/inline.html" $cfg.i18n.llms_index_entry_note) -}} {{- $routes = $routes | append $indexItem -}} {{- end -}} {{- end -}} {{- end -}} {{- with $routes -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $cfg.i18n.llms_start_heading)) | append "" -}} {{- range . -}}{{- $lines = $lines | append . -}}{{- end -}} {{- end -}} {{/* 7. One H2 per configured section. Membership comes from the shared filter through lib/section-pages.html -- the ONE implementation both documents call -- so llms.txt can never list a page the twins and robots.txt disagree about, and the compact and complete files can never disagree about what a section holds. Each entry's `section` value arrived here already normalized by config.html, so a bare name and a slashed form resolve identically -- an unnormalized mismatch would render an empty H2 with no warning, no error and exit 0. The COMPACT document then applies the entry's selection principle through lib/llms-select.html, and says so in the section when that step dropped anything; the COMPLETE document skips both and lists the section as the walk yields it. That is the whole difference between the two files, and it is why "the complete index is never truncated" is a property of this branch rather than a claim about configuration: no `limit`, `select` or `order` value can reach the complete listing, and nothing there has an omission to disclose. The shared page filter still applies to both -- a page carrying `agent: false`, a noindexed page, the search page, or a page outside the `sections` allow-list is absent from every surface, complete index included. Excluded from every surface is a different thing from omitted by a cap, and only the second is what the complete index restores -- and only the second is what the notice discloses. */}} {{- range $entry := $llms.sections | default slice -}} {{- $section := $entry.section | default "" -}} {{- $name := $entry.name | default "" -}} {{/* Two entry shapes are refused rather than rendered, because both fail INVISIBLY -- exit 0, plausible-looking output, wrong content. An empty `section` matches EVERY page: the prefix test degenerates to hasPrefix .Path "/", which every page in the site satisfies. A single `sections =` for `section =` typo would therefore publish the entire site under one heading and look deliberate. An entry with no `name` has no H2 to open, and because the document is assembled as one flat slice of lines its bullets would be appended directly beneath the PREVIOUS entry's last bullet, where every Markdown parser reads them as that section's links. */}} {{- if not $section -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:llms-section-empty:%s" $name) "message" (printf "[agent-readiness] Skipping the [[params.agent.llms.sections]] entry named %q: its `section` is empty, and an empty section matches every page, so the entry would list the whole site under one heading. Set `section` to a section path such as '/blog' -- note the key is `section`, singular." $name)) -}} {{- else if not $name -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:llms-section-unnamed:%s" $section) "message" (printf "[agent-readiness] Skipping the [[params.agent.llms.sections]] entry for %q: it has no `name`, so it has no H2 of its own and its links would be read as belonging to the section above it. Give the entry a `name`." $section)) -}} {{- else -}} {{- $matched := partialCached "agent-readiness/lib/section-pages.html" (dict "page" $page "cfg" $cfg "section" $section) $section site.Language.Name -}} {{- $items := $matched -}} {{- if not $complete -}} {{- $items = partial "agent-readiness/lib/llms-select.html" (dict "cfg" $cfg "entry" $entry "items" $matched) -}} {{- end -}} {{/* An empty listing withholds its heading, whichever step emptied it, because an empty H2 in a link index reads as "this site has no blog posts" rather than as "this configuration is wrong". Omitting rather than falling back is correct specifically under the two-document split: the complete index still carries the section and the compact file names the complete index, so the cost is reach, not access. */}} {{- if not $items -}} {{- if not $matched -}} {{- partial "agent-readiness/lib/warn.html" (dict "key" (printf "agent-readiness:warn:llms-section-empty-result:%s" $section) "message" (printf "[agent-readiness] The [[params.agent.llms.sections]] entry %q matches no page at %q, so its heading is omitted rather than published empty. Check the section path against your content tree, and check that it is admitted by the top-level `sections` allow-list if you set one." $name $section)) -}} {{- end -}} {{- else -}} {{- $lines = $lines | append "" | append (printf "## %s" (partial "agent-readiness/lib/inline.html" $name)) | append "" -}} {{/* THE SELECTION DISCLOSES ITSELF. The condition is the only honest one available: the shared filter ADMITTED $matched pages and the selection KEPT $items of them, so a section that dropped nothing -- an uncapped `select = 'first'`, `select = 'all'`, a flag every page carries -- says nothing, and its lines stay byte-identical to what this renderer emitted before the notice existed. `not $complete` is REDUNDANT today and is kept deliberately. The complete branch never calls lib/llms-select.html, so its $items IS its $matched and the length test already excludes it; deleting the conjunct changes no published byte, and no assertion can see it (verified by mutation). It states the invariant STRUCTURALLY instead: "the complete index never discloses an omission" then survives any future change that lets those two collections differ there, rather than depending on a coincidence of the current code. */}} {{- if and (not $complete) (lt (len $items) (len $matched)) -}} {{- $lines = $lines | append (partial "agent-readiness/lib/llms-partial-notice.html" (dict "cfg" $cfg "url" $indexUrl "kept" (len $items) "total" (len $matched))) -}} {{- end -}} {{- range $items -}} {{- $lines = $lines | append (partial "agent-readiness/lib/llms-entry.html" (dict "item" . "cfg" $cfg)) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{/* 8. The Optional section: links an agent may drop when shortening context. It holds the consumer's declared entries, collected at the top of this file, plus the module's own derived entry below, and the H2 is emitted only when at least one entry of either kind survived, because an empty H2 claims a section that is not there. The module's own Agent Skills index belongs HERE rather than in slot 6, and the contrast is the reason slot 6 exists: the skills index is genuinely secondary -- a machine-readable listing an agent can drop without losing the site -- while the home twin is the front door and the complete index is the only route to what a cap dropped.
