{{/* agent-readiness/lib/skills-index-url.html -- utility (LIB tier). Purpose: the ONE answer to "does the Agent Skills index actually publish, and at which URL". agent-readiness/surfaces.html reads it for the public surface enumeration, and agent-readiness/llms.html reads it to append the module's own index entry to llms.txt's `## Optional` section; factoring the answer here keeps the two callers from ever drifting apart on the gate set. PUBLISHED, not merely wired. Whether anything publishes is lib/skills-entries.html's answer, which carries the gates and the shared resolution cache; this partial adds only the URL, so the two projections of one resolution cannot disagree about whether there is an index to name. WHICH HOST'S INDEX IT NAMES. The format sets root = true, which on a shared domain pins ONE file for the whole site -- the default language emits it and every language names it. Under multihost each host has its own publish root, so each host publishes and serves a copy of its own, and naming the default host's would send a reader of THIS host to another one. So the rendering page's site supplies the URL there, when a caller passed a page; a caller that passes none keeps the default site's answer, which is correct on every shared-domain build and is the only answer available without one. Expected context (dict): - .page (Page) OPTIONAL. Only read on a multihost build, to name the host now rendering rather than the default one. Return value: the index's ABSOLUTE Permalink (string) when the surface publishes, else "". ONE terminal return. */}} {{- $page := .page -}} {{- $url := "" -}} {{- with partial "agent-readiness/lib/skills-entries.html" dict -}} {{- $home := hugo.Sites.Default.Home -}} {{- if and hugo.IsMultihost (reflect.IsPage $page) -}} {{- $home = $page.Site.Home -}} {{- end -}} {{- with $home.OutputFormats.Get "agentskills" -}} {{- $url = .Permalink -}} {{- end -}} {{- end -}} {{- return $url -}}
