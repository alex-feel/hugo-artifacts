The module's own surfaces answer two DIFFERENT time questions and must never conflate them: `last_updated` in a twin is the page's Lastmod, i.e. when the CONTENT changed, while this value is when the BUILD ran. A daily rebuild refreshes generated figures without touching a content file, so `last_updated` sits still while the document changes -- and only a build stamp lets a reader ask "am I holding a cached copy". A reader comparing two surfaces compares like with like only if each name means one thing everywhere, which is why this is never folded into `last_updated`. Value semantics: the string is constant for the whole build and identical in every document the build publishes, in every language.
