{{/* seo/alternates.html -- renderer (RENDERER tier). Purpose: emit two head surfaces the module previously had no home for -- alternate REPRESENTATIONS of the current page, and the IANA-registered link relations whose target is a fixed sitewide URL. Called from head-meta.html immediately AFTER the feed-discovery block, so feed emission is unchanged. Expected context: $ctx = {page, seo} as assembled by seo/head.html. Return value: none. This partial renders. Both surfaces are entirely opt-in: with [seo.alternates] and [seo.links] unset, this partial emits nothing at all and the head is byte-identical to a build without it. ---- Surface one: alternate representations ---- Driven by an EXPLICIT ALLOW-LIST, never a blanket range over .AlternativeOutputFormats: [seo.alternates] formats = ['markdown'] A blanket range would advertise /searchindex.json and /manifest.webmanifest as page alternates, which is exactly why head-meta.html narrows its own feed emission to the RSS format. That filter is correct and stays; this is a second, separately-gated emitter. Without this, a site publishing Markdown twins publishes them and never links them. ---- Surface two: static link relations ---- [seo.links] privacy_policy = '/privacy-policy/' author = '/authors/jane-doe/' search = '/opensearch.xml' license = 'https://creativecommons.org/licenses/by/4.0/' Only these four keys are recognized. RFC 8288 permits an un-prefixed relation name only when it is IANA-registered; anything else requires a full extension URI, so an unrecognized key warns once and is SKIPPED rather than emitted as a bare token that no client can interpret. Deliberately absent, each rejected on the merits: `terms-of-service` (no such page on a site that has not published one), `describedby` (targets POWDER description resources from an effectively extinct effort), `index` (an HTML 4.01 relic with no unambiguous referent), `related` (expresses exactly one undifferentiated target, a strict downgrade from a labeled cross-link graph), `hub` (requires a genuinely running WebSub hub, and advertising one without it silently breaks every subscriber), and `sitemap` (never an IANA-registered relation at all -- the standard channel is the robots.txt Sitemap directive). */}} {{- $page := .page -}} {{- $seo := .seo -}} {{/* ---- Alternate representations ---- Coerced through as-list.html rather than gated on IsSlice: gating made `formats = 'markdown'` behave exactly like unset, so the twins were published and never linked -- silently disabling the one surface this partial exists to provide. Both comment markers are trimmed. An untrimmed comment preserves the newline before it, which is precisely the stray blank line the regression lock in 01-alternates.spec.js was written to catch. */ -}} {{- range partial "seo/lib/as-list.html" ($page.Param "seo.alternates.formats") -}} {{- $name := trim (printf "%v" .) " \t\n\r" -}} {{- with $name -}} {{- with $page.OutputFormats.Get . }} {{- end -}} {{- end -}} {{- end -}} {{/* ---- Static link relations ---- Emission is unconditional on the configured value being non-empty, on every page this module's head runs on, because each of these targets is constant sitewide. */}} {{- with $page.Param "seo.links" -}} {{- $links := . -}} {{- if reflect.IsMap $links -}} {{- $ogSiteName := $page.Param "seo.organization.name" | default ($page.Param "seo.website.name") | default site.Title -}} {{- range $key, $value := $links -}} {{- $k := lower (trim (printf "%v" $key) " \t\n\r") -}} {{/* Absolutized through the shared routine rather than by piping into absURL directly: a value that already starts with "/" -- which is the form this module documents for all four keys -- resolves against the protocol and host only, discarding the baseURL path, so the direct form emits a 404 in the head of every page on a subpath deployment. */}} {{- $v := partial "seo/lib/absolute-url.html" $value -}} {{- if $v -}} {{- if eq $k "privacy_policy" }} {{- else if eq $k "author" }} {{- else if eq $k "license" }} {{- else if eq $k "search" }} {{- else -}} {{- partial "seo/lib/warn.html" (dict "key" (printf "seo:warn:unknown-link-rel:%s" $k) "message" (printf "[seo] Ignoring the unknown [seo.links] key %q: only privacy_policy, author, search and license are recognized. RFC 8288 allows an un-prefixed relation name only when it is IANA-registered, so emitting %q as a bare token would produce a relation no client can interpret." $k $k)) -}} {{- end -}} {{- end -}} {{- end -}} {{- else -}} {{/* Set but not a table -- the bracket array-of-tables form, say. Gating silently would lose rel="license", rel="author", rel="search" and rel="privacy-policy" from every page, which is the same behaves-exactly-like-unset failure this file rejects for `formats` twenty lines above. The else nests INSIDE the `with`, so the unset case stays silent. */}} {{- partial "seo/lib/warn.html" (dict "key" "seo:warn:links-not-a-table" "message" (printf "[seo] Ignoring [seo.links]: it expects a table of relation name to URL, but was given %q. Write it as [params.seo.links] with one key per relation." (printf "%v" $links))) -}} {{- end -}} {{- end -}}
