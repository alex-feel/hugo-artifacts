{{/* Resolves the page title once for every downstream surface. Pure value chooser: no HTML, no side effects. Context: the current Page, passed as the dot. Returns a dict {title, titleFull}: - title: the entity title with NO suffix; feeds og:title, twitter:title, JSON-LD headline, WebPage.name, and the like. - titleFull: the element ONLY -- title + params.seo.title_suffix off the home page, the declared SEO title on it. Title chain: seo.title -> meta_title (alias) -> .Title -> (home only) params.seo.organization.name -> site title. The home page's <title> follows the DECLARED SEO title -- seo.title, or its meta_title alias -- and falls back to the site title. The home page's own `title` front matter is deliberately NOT in that chain: it is the content title, routinely written as "Home" to name a menu entry, and a search result headlined "Home" is worse than one headlined with the site's name. So a home page either states its search headline outright or inherits the site's name, while og:title keeps reading the full chain -- a share card may carry the content title even where the SERP carries the brand. The suffix is a SERP display device and never reaches the home page: a home <title> is never "Home | Acme" or "Acme | Acme". A home page that wants a suffixed headline writes the whole string, suffix included, into seo.title. The legacy alias params.metadata.title_suffix is honored when params.seo.title_suffix is absent. Site-level fallbacks read the page's OWN language site rather than the global `site`, which is the RENDERING language: this resolver is also asked about a foreign page, because resolve/image.html requests an alt fallback for whatever page it was handed, and resolve/author.html hands it an author page resolved from the default-language site while a translation renders. ONE terminal return. */}} {{- $page := . -}} {{/* Title, first non-empty wins. $declared records that the value came from a key whose only purpose is to name the SEO title, which is what lets the home branch below tell "this page states its headline" from "this page merely has a content title". */}} {{- $title := "" -}} {{- $declared := false -}} {{- with $page.Param "seo.title" -}} {{- $title = . -}} {{- $declared = true -}} {{- else with $page.Params.meta_title -}} {{- $title = . -}} {{- $declared = true -}} {{- else with $page.Title -}} {{- $title = . -}} {{- else -}} {{- if $page.IsHome -}} {{- with $page.Param "seo.organization.name" -}} {{- $title = . -}} {{- else -}} {{- $title = $page.Site.Title -}} {{- end -}} {{- else -}} {{- $title = $page.Site.Title -}} {{- end -}} {{- end -}} {{- $suffix := "" -}} {{- with $page.Param "seo.title_suffix" -}} {{- $suffix = . -}} {{- else with $page.Param "metadata.title_suffix" -}} {{- $suffix = . -}} {{- end -}} {{- $titleFull := $title -}} {{- if $page.IsHome -}} {{- if not $declared -}} {{- $titleFull = $page.Site.Title -}} {{- end -}} {{- else -}} {{- with $suffix -}} {{- $titleFull = printf "%s%s" $title . -}} {{- end -}} {{- end -}} {{- return dict "title" $title "titleFull" $titleFull -}}
