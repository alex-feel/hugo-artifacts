{{/* Resolves the ONE unified description shared by the meta description, og:description, twitter:description, and every JSON-LD description. Resolving it once makes cross-surface divergence structurally impossible. Pure value chooser: no HTML, no side effects. Context: the current Page, passed as the dot. Description chain (first non-empty wins): page seo.description (front matter) -> meta_description (alias) -> .Description -> .Summary | plainify | truncate 200 (only when the page has content) -> params.seo.description (site) (alias params.metadata.description) -> site.Params.description The page-level seo.description is read directly from front matter so the site-level params.seo.description can sit BELOW .Description/.Summary as a last-resort default; .Summary sits late because auto-summaries are noisy, so an explicit description always wins. Returns: the description string (may be ""). ONE terminal return. */}} {{- $page := . -}} {{/* Page-level seo.description, read straight from front matter (not the .Param cascade) so it does not absorb the site default prematurely. */}} {{- $pageSeo := partial "seo/lib/as-map.html" (dict "value" ($page.Params.seo) "key" "seo" "warn_falsy" true) -}} {{- $description := "" -}} {{- with (index $pageSeo "description") -}} {{- $description = . -}} {{- else with $page.Params.meta_description -}} {{- $description = . -}} {{- else with $page.Description -}} {{- $description = . -}} {{- else -}} {{/* .Summary fallback only for pages that actually carry content. */}} {{- if $page.Content -}} {{- with $page.Summary -}} {{- $description = . | plainify | strings.TrimSpace | truncate 200 -}} {{- end -}} {{- end -}} {{- if not $description -}} {{/* Site-level fallbacks read the page's OWN language site, not the global `site` (the rendering language), so a translated page falls back to its own language's defaults. */}} {{- with (partial "seo/lib/as-map.html" (dict "value" (index $page.Site.Params "seo") "key" "params.seo" "warn_falsy" true)).description -}} {{- $description = . -}} {{- else with (partial "seo/lib/as-map.html" (dict "value" (index $page.Site.Params "metadata") "key" "params.metadata" "warn_falsy" true)).description -}} {{- $description = . -}} {{- else with $page.Site.Params.description -}} {{- $description = . -}} {{- end -}} {{- end -}} {{- end -}} {{- return $description -}}
