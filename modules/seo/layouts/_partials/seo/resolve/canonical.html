{{/* Resolves the absolute canonical URL for the page (seo.canonical -> canonical alias -> .Permalink). Pure value chooser: no HTML, no side effects. Context: the current Page, passed as the dot. Chain (first non-empty wins): seo.canonical (via .Param cascade) -> canonical (legacy front-matter alias) -> .Permalink (Hugo-native, already absolute) An explicit override that is relative is absolutized with absURL; .Permalink is already absolute so it passes through. Resolving exactly one absolute self-referencing canonical guarantees a page never emits duplicate or conflicting rel="canonical" links. Returns: the absolute canonical URL string. ONE terminal return. */}} {{- $page := . -}} {{/* Both consumer-authored overrides go through seo/lib/absolute-url.html rather than straight into absURL: a value beginning with "/" resolves against the protocol and host ONLY, discarding the baseURL's path, so on a subpath deployment `canonical: '/about/'` would declare a canonical URL outside the site -- the one tag whose whole job is to be exactly right. */}} {{- $canonical := "" -}} {{- with $page.Param "seo.canonical" -}} {{- $canonical = partial "seo/lib/absolute-url.html" (dict "value" . "key" "seo.canonical" "scope" $page.RelPermalink) -}} {{- else with $page.Params.canonical -}} {{- $canonical = partial "seo/lib/absolute-url.html" (dict "value" . "key" "canonical" "scope" $page.RelPermalink) -}} {{- end -}} {{/* The .Permalink fallback is applied AFTER the override chain rather than as its else branch, so it also catches an override that was PRESENT but unusable -- a key written as a table, which `with` treats as present and the absolutizer resolves to "". Emitting no canonical at all is the worst of the three outcomes: the self-referencing permalink is always a correct answer, so a malformed override degrades to it instead of removing the tag the page would otherwise have had. */}} {{- if not $canonical -}} {{- $canonical = $page.Permalink -}} {{- end -}} {{- return $canonical -}}
