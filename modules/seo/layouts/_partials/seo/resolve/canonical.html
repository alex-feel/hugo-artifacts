{{/* Resolves the absolute canonical URL for the page (seo.canonical -> canonical alias -> .Permalink). Pure value chooser: no HTML, no side effects. Context: the current Page, passed as the dot. Chain (first non-empty wins): seo.canonical (via .Param cascade) -> canonical (legacy front-matter alias) -> .Permalink (Hugo-native, already absolute) An explicit override that is relative is absolutized with absURL; .Permalink is already absolute so it passes through. Resolving exactly one absolute self-referencing canonical guarantees a page never emits duplicate or conflicting rel="canonical" links. Returns: the absolute canonical URL string. ONE terminal return. */}} {{- $page := . -}} {{/* Both consumer-authored overrides go through seo/lib/absolute-url.html rather than straight into absURL: a value beginning with "/" resolves against the protocol and host ONLY, discarding the baseURL's path, so on a subpath deployment `canonical: '/about/'` would declare a canonical URL outside the site -- the one tag whose whole job is to be exactly right. */}} {{- $canonical := "" -}} {{- with $page.Param "seo.canonical" -}} {{- $canonical = partial "seo/lib/absolute-url.html" . -}} {{- else with $page.Params.canonical -}} {{- $canonical = partial "seo/lib/absolute-url.html" . -}} {{- else -}} {{- $canonical = $page.Permalink -}} {{- end -}} {{- return $canonical -}}
