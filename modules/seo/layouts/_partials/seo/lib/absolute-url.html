{{/* seo/lib/absolute-url.html -- internal utility. Purpose: turn a consumer-authored URL into an absolute one for emission into . THE TRAP THIS EXISTS TO AVOID: `absURL` does NOT prepend the whole baseURL to a value that already starts with "/". Hugo documents that form as relative to the protocol and host only, DISCARDING the baseURL's path. So with baseURL = "https://example.org/docs/", `absURL "/privacy-policy/"` yields "https://example.org/privacy-policy/" -- outside the site, a 404 in the head of every page -- while `absURL "privacy-policy/"` correctly yields "https://example.org/docs/privacy-policy/". The leading-slash form is the form this module's own README and docstrings document, so it is the form most consumers write, and it is exactly the one that breaks. Normalizing here rather than at each call site keeps every emitted href honest on subpath deployments. Values carrying their own scheme (https:, mailto:, tel:) and protocol-relative values (//host/path) are returned untouched: absolutizing them would corrupt them. A non-scalar value (a table, a list, or a boolean) yields "" and warns once: stringifying one would publish Go's debug form (map[...]) as a URL, and dropping it in silence would leave a consumer staring at a missing tag with nothing to explain it, so it degrades through the same warn-and-skip idiom every other shape mistake in this module uses. Note that `with` treats a non-empty table as PRESENT, so a key written as a table really does arrive here rather than being skipped upstream. Expected context (dict): - .value (any) - the consumer-authored URL. - .key (string) - the config key, named in the warning. - .scope (string) - optional. Appended to the dedup key so a page-authored value warns once per page; omit for site-level config, which warns once per build. Return value: the absolute URL, or "" for an empty or non-scalar input. ONE terminal return. */}} {{- $v := .value -}} {{- $key := .key -}} {{- $u := "" -}} {{- if and (ne $v nil) (not (reflect.IsMap $v)) (not (reflect.IsSlice $v)) (ne (printf "%T" $v) "bool") -}} {{- $u = trim (printf "%v" $v) " \t\n\r" -}} {{- else if ne $v nil -}} {{- partial "seo/lib/warn.html" (dict "key" (printf "seo:warn:non-scalar-url:%s:%s" $key (.scope | default "")) "message" (printf "[seo] Ignoring %s: it expects a URL written as a single value, but a table, list, or boolean arrived, so no URL is emitted for it." $key)) -}} {{- end -}} {{- $out := "" -}} {{- with $u -}} {{- if or (hasPrefix . "//") (findRE `^[a-zA-Z][a-zA-Z0-9+.\-]*:` .) -}} {{- $out = . -}} {{- else -}} {{- $out = strings.TrimPrefix "/" . | absURL -}} {{- end -}} {{- end -}} {{- return $out -}}
