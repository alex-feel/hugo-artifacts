{{/* Renders one avatar image with its placeholder fallback -- the single owner of the avatar contract for every call site (the identity strip and both organization lists), so all of them render and degrade the same way. Modes (the shortcode's avatar parameter; the CALLER handles "none" itself, because what "no avatar" renders is each caller's own baseline): - "fetch": copy the image at build time with resources.GetRemote, so the published output is self-contained. The fetch is a single try-wrapped attempt rather than a run through fetch.html's retry loop -- an avatar is a CDN object, not an API endpoint, and the loop's classification, budgets and circuit breaker guard the API. Any failure (transport error, or an HTTP error page arriving as a nil resource) degrades to the placeholder with ONE warning per cache key: the same image can be rendered from several sections and several profiles in one build, and the build should name each problem once. Reading .RelPermalink is what publishes the copy, and the copy is registered with the sibling url-retirement module's manifest when a site imports both (see the comment at the call). - "hotlink": reference the URL directly. Nothing is published, so nothing is registered. An empty .url renders the placeholder WITHOUT a warning: the API answered and simply carried no avatar, which is the caller's data to explain, not a fetch failure. Context expectations: - .url (string) Avatar URL; may be empty. - .mode (string) "fetch" or "hotlink" (the caller filters out "none"). - .class (string) BEM class; the placeholder appends a "--placeholder" modifier of the same base. - .alt (string) Alternative text; "" when the adjacent text already carries the name, so the image stays decorative. - .size (int) Intrinsic width and height attributes. - .icon (string) github-profile/icon.html name for the placeholder. - .cacheKey (string) resources.GetRemote key, and the axis the warning deduplicates on (1:1 with .warnSubject, so one key never serves two wordings). - .warnSubject (string) The failing thing, as it should read mid-sentence in the warning (for example: the avatar of user "octocat"). - .position Shortcode call position, named in the warning. */}} {{- $url := .url -}} {{- $mode := .mode -}} {{- $class := .class -}} {{- $alt := .alt -}} {{- $size := .size -}} {{- $icon := .icon -}} {{- $cacheKey := .cacheKey -}} {{- $warnSubject := .warnSubject -}} {{- $position := .position -}} {{- $shown := false -}} {{- $failure := "" -}} {{- if $url -}} {{- if eq $mode "fetch" -}} {{- with try (resources.GetRemote $url (dict "key" $cacheKey)) -}} {{- with .Err -}} {{- $failure = "transport" -}} {{- else with .Value -}} {{- /* Reading that URL published the copy, and no walk of .Site.Pages can see it, so the sibling url-retirement module is told behind the guard that costs a site without it nothing. The name is stable rather than content-addressed -- measured at v0.164.0, a GetRemote resource is named and published as _., unchanged when the bytes served at the URL change -- so it survives url-retirement's content-addressed refusal; the resource is handed over rather than its URL because url-retirement owns that distinction. The page is the RENDERING language's home: what a registration picks is which language's manifest the URL belongs to. This runs in the html pass (weight 10), so it is always in time for the manifest's weight-100 pass. The delimiters are trimmed so the branch keeps emitting the img tag with zero trailing bytes. */ -}} {{- if templates.Exists "_partials/url-retirement/register-url.html" -}} {{- partial "url-retirement/register-url.html" (dict "page" site.Home "resource" .) -}} {{- end -}} {{- $shown = true -}} {{- else -}} {{- $failure = "not-found" -}} {{- end -}} {{- end -}} {{- else -}} {{- $shown = true -}} {{- end -}} {{- end -}} {{- if $failure -}} {{/* One warning per cache key, serialized through partialCached: pages render concurrently, and a bare check-then-set lets several of them pass the check before any writes. The failure class cannot vary within a build -- GetRemote memoizes the result under the key -- so one key serves one wording. */}} {{- partialCached "github-profile/avatar-warn.html" (dict "failure" $failure "subject" $warnSubject "position" $position "key" $cacheKey ) $cacheKey -}} {{- end -}} {{- if not $shown -}} {{- partial "github-profile/icon.html" (dict "name" $icon "class" "github-profile__icon") -}} {{- end -}}
