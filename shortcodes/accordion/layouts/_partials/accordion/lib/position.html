{{/* RETURNS the diagnostics position for a shortcode call: its own .Position when it is top-level, and its OUTERMOST ancestor's otherwise. Measured at Hugo v0.164.0, a nested shortcode's own .Position collapses to ":1:1" -- the real line and column survive only for a top-level call -- so a warning that quoted an item's own position would send the author to the top of the file. The outermost ancestor's position is accurate, and it points at the accordion container the item was authored in, which is where the author looks anyway. Context: the shortcode object itself (pass `.`). Return value: string. Exactly one terminal return. */}} {{- $result := printf "%s" .Position -}} {{- with .Parent -}} {{- $result = partial "accordion/lib/position.html" . -}} {{- end -}} {{- return $result -}}
